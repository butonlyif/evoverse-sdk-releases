ARCHITECTURE

One SDK, Two Chips in Fusion: Efinity FPGA + RK3588 SoC

Every boundary — host editor to SDK Core, Core to each Adapter — is an explicit contract: upper layers only orchestrate and present, while toolchain capabilities are provided by Adapters and installed on demand. The FPGA side owns the video pipeline, RTL and timing closure; the SoC side owns BSP cross-compilation, the firmware baseline and NPU/LLM inference — both sides share one evidence chain, and more target platforms can join later. For the layered details see SDK Overview.
