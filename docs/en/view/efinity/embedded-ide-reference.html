Efinity Embedded IDE Reference

Efinity Embedded Software Development IDE Reference

Version: v1.0 | Based on Efinity 2026.1

1. Overview

The Efinity embedded software IDE (efx_code.bat) is the integrated development environment for the RISC-V processors (Sapphire SoC / VexRiscv) inside Efinix FPGAs. It is built on Eclipse CDT + the GNU MCU Eclipse plugins + OpenOCD and supports two software runtimes: standalone (bare-metal) and FreeRTOS.

Launching:

efx_code.bat [workspace_path]

What it actually runs:

:: 2026.1.132.1
setlocal
call "%~dp0setup.bat"
"python3.bat" -m els_shell -e %*
endlocal

In other words, it launches the Eclipse embedded development environment through the els_shell Python module.

6. Launch configuration

An Eclipse-style XML launch configuration file for GDB + OpenOCD debug sessions:

<launchConfiguration type="ilg.gnumcueclipse.debug.gdbjtag.openocd.launchConfigurationType">
    <!-- OpenOCD settings -->
    <stringAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerExecutable" value="openocd"/>
    <intAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerGdbPortNumber" value="3333"/>
    <intAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerTelnetPortNumber" value="4444"/>
    <intAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerTclPortNumber" value="6666"/>
    <stringAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerOther"
        value="-f ${workspace_loc}\bsp\efinix\EfxSapphireSoc\openocd\ftdi.cfg
               -f ${workspace_loc}\bsp\efinix\EfxSapphireSoc\openocd\debug.cfg"/>

    <!-- GDB client settings -->
    <stringAttribute key="org.eclipse.cdt.dsf.gdb.DEBUG_NAME" value="riscv-none-embed-gdb"/>
    <stringAttribute key="org.eclipse.cdt.debug.gdbjtag.core.gdbClientOtherCommands"
        value="set mem inaccessible-by-default off
               set arch riscv:rv32
               set remotetimeout 250"/>
    <stringAttribute key="org.eclipse.cdt.debug.gdbjtag.core.stopAt" value="main"/>

    <!-- Connection settings -->
    <stringAttribute key="org.eclipse.cdt.debug.gdbjtag.core.ipAddress" value="localhost"/>
    <intAttribute key="org.eclipse.cdt.debug.gdbjtag.core.portNumber" value="3333"/>
    <booleanAttribute key="org.eclipse.cdt.debug.gdbjtag.core.useRemoteTarget" value="true"/>
</launchConfiguration>

Key parameters: | Parameter | Value | Description | |------|-----|------| | Debugger | riscv-none-embed-gdb | RISC-V GDB debugger | | OpenOCD GDB port | 3333 | GDB connection port | | OpenOCD Telnet port | 4444 | Telnet control port | | OpenOCD Tcl port | 6666 | Tcl script port | | Target address | localhost | Local debugging |

Launch configuration variants: | File | Purpose | |------|------| | default.launch | Standard FTDI debugging | | default_ti.launch | Titanium devices | | default_softTap.launch | Soft TAP mode |

7. Build system

Toolchain

  • Compiler: riscv64-unknown-elf-gcc
  • GDB: riscv-none-embed-gdb
  • OpenOCD: an OpenOCD build supporting FTDI interfaces

Makefile system

standalone.mk    →  generic standalone build rules
bsp.mk           →  BSP-related build rules
riscv64-unknown-elf.mk  →  toolchain paths and flags

Build artifacts

File Description
.elf ELF executable
.bin Binary image
.hex Intel HEX format
.map Memory map file
.asm Disassembly output

8. Bootloader

Configuration file: bootloaderConfig.h (defines bootloader parameters such as the Flash base address and size)

Linker script: bootloader.ld

Binary tool: binGen.py — merges the bootloader and the application into a single binary - Input: bootloader binary + application binary - Output: merged .bin file - See: tool/README-binGen.txt

10. Interrupts and exception handling

Startup code (assembly): | File | Function | |------|------| | start.S | Main startup code (stack setup, BSS zeroing, jump to main)| | start_int.S | Startup code with an interrupt vector table | | smpInit.S | SMP multi-core initialization | | smpFunc.S | SMP inter-core communication functions | | trap.S | Exception/interrupt handler entry |

11. Semihosting support

semihosting.h provides semihosting, letting an embedded program talk to the host over the JTAG debug interface (e.g. printf output to the debug console).
