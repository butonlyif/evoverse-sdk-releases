1.3.2 PCIe Interface Details

The RK3588 has a built-in PCIe Gen3 x4 controller, usually acting as Root Complex (RC), with the FPGA as Endpoint (EP):

  • Lane configuration: PCIe Gen3 x4, theoretical bandwidth ~4 GB/s (~1 GB/s per lane)
  • BAR space: the FPGA EP exposes BAR0~BAR5, with a typical allocation:
  • BAR0: 32-bit non-prefetchable memory for control registers (e.g., 1 MB)
  • BAR2: 64-bit prefetchable memory for DMA buffers (e.g., 256 MB)
  • Interrupts: use MSI/MSI-X, so no extra GPIO interrupt line is needed
  • MSI: the FPGA can be allocated up to 32 MSI vectors
  • MSI-X: supports a per-vector independent address, suitable for multi-queue scenarios
  • Address mapping: FPGA registers are mapped into RK3588 memory space through the PCIe BARs
  • Kernel driver: use the standard pci_driver framework and match by PCI vendor/device/subsystem ID; a PCIe EP is an enumerable device and does not use DT compatible as its usual binding mechanism

PCIe node reference in the Device Tree:

&pcie3x4 {
    status = "okay";
    // FPGA Endpoint configuration
};

1.3.3 GE Ethernet (RGMII) Details

Use an RK3588 GMAC controller, connected over RGMII to an Ethernet PHY implemented inside the FPGA:

  • Interface: RGMII (Reduced Gigabit Media Independent Interface)
  • TXC/TX_CTL/TXD[3:0]: transmit path
  • RXC/RX_CTL/RXD[3:0]: receive path
  • MDC/MDIO: PHY management interface, used to configure the FPGA-internal PHY registers
  • PHY address: the FPGA-internal PHY gets an address over MDIO (usually 0~31)
  • Clocking scheme:
  • The RK3588 provides the TXC clock (125 MHz DDR)
  • RXC is recovered by the FPGA PHY and fed back to the RK3588
  • MAC address:
  • Recommended: read a unique MAC from the RK3588 OTP/eFuse
  • Without OTP programming, pin it in the Device Tree via local-mac-address
  • Kernel driver: use the standard stmmac (Synopsys GMAC) driver, which discovers and configures the PHY over MDIO

GMAC node configuration in the Device Tree:

&gmac0 {
    phy-mode = "rgmii-rxid";
    // FPGA-internal PHY, MDIO address is usually 0
    fixed-link {
        speed = <1000>;
        full-duplex;
    };
};

1.3.4 MIPI Interface Details

The RK3588 provides multiple MIPI interfaces for FPGA video-stream transport:

MIPI CSI (Camera Serial Interface) — FPGA → RK3588 video input: - Purpose: the FPGA acts as the video source and sends the processed image stream to the RK3588 over CSI - Controller: RK3588 VICAP (Video Input Capture) - Lane configuration: 4-lane, up to 2.5 Gbps per lane - Data formats: RAW8/RAW10/RAW12, YUV422, RGB888, etc. - Virtual channels: supports 4 virtual channels that can be multiplexed - Driver framework: V4L2 (video4linux2), accessed from user space via /dev/videoX

MIPI DSI (Display Serial Interface) — RK3588 → FPGA display output: - Purpose: the RK3588 sends display content to the FPGA over DSI for further processing or forwarding - Controller: RK3588 VOP (Video Output Processor) with its internal DSI controller - Lane configuration: 4-lane, up to 2.5 Gbps per lane - Resolution: up to 4K@60Hz (depending on what the FPGA can receive) - Driver framework: DRM (Direct Rendering Manager), accessed via /dev/dri/cardX

MIPI node configuration in the Device Tree:

&csi2_dphy0_hw {
    status = "okay";
};

&csi2_dphy0 {
    status = "okay";

&dsi0 {

1.3.5 GPIO Interface Details

The low-speed control signals between the FPGA and the RK3588 are implemented over GPIO:

Signal Direction Purpose Recommended GPIO
FPGA_RESET RK→FPGA FPGA reset control (active-low) Any GPIO, open-drain output
FPGA_IRQ FPGA→RK Interrupt request from the FPGA to the RK3588 An IRQ-capable GPIO
FPGA_DONE FPGA→RK FPGA configuration-done indication Any GPIO input
FPGA_INIT FPGA→RK FPGA initialization status Any GPIO input
FPGA_MODE[1:0] RK→FPGA FPGA boot mode selection Any GPIO output
FPGA_STATUS FPGA→RK FPGA run status indication Any GPIO input
SYS_PWR_EN RK→FPGA System power enable Any GPIO output

GPIO usage notes: - Confirm the GPIO pins are not taken by system peripherals (UART, I2C, SPI, etc.) - Interrupt pins must use a GPIO controller that supports interrupt-parent - Open-drain output pins (FPGA_RESET) need an external pull-up resistor - High-speed signals should not go through GPIO; use dedicated interfaces (PCIe/MIPI)

&pinctrl {

                <0 RK_PA2 RK_FUNC_GPIO &pcfg_pull_none>;   // FPGA_DONE

    };
};

2.4 parseReport Implementation

// rk3588Adapter.ts

parseReport(rawOutput: string[]): BuildReport {
  const report: BuildReport = {
    success: true,
    stages: [],
    errors: [],
    warnings: [],
    artifacts: [],
    timing: {},
  };

  for (const line of rawOutput) {
    // U-Boot build stage
    if (this.isUBootStage(line)) {
      report.stages.push(this.parseUBootStage(line));
    }

    // Kernel build stage
    if (this.isKernelStage(line)) {
      report.stages.push(this.parseKernelStage(line));
    }

    // Buildroot build stage
    if (this.isBuildrootStage(line)) {
      report.stages.push(this.parseBuildrootStage(line));
    }

    // Error parsing
    if (this.isError(line)) {
      report.errors.push(this.parseError(line));
      report.success = false;
    }

    // Warning parsing
    if (this.isWarning(line)) {
      report.warnings.push(this.parseWarning(line));
    }

    // Artifact paths
    if (this.isArtifact(line)) {
      report.artifacts.push(this.parseArtifact(line));
    }
  }

  return report;
}

// ── Buildroot-specific parsing ──

parseBuildrootStage(line: string): BuildStage {
  // Buildroot output format: ">>> toolchain 1.0 Building..."
  const match = line.match(/>>>\s+(\S+)\s+Building/);
  if (match) {
    return {
      name: match[1],
      status: 'building',
      startTime: this.parseTimestamp(line),
    };
  }

  // Success marker: ">>> toolchain 1.0 Done"
  const doneMatch = line.match(/>>>\s+(\S+)\s+Done/);
  if (doneMatch) {
    return {
      name: doneMatch[1],
      status: 'success',
      duration: this.parseDuration(line),
    };
  }

  // Progress: "[  25%]" or "[100%]"
  const progressMatch = line.match(/\[(\d+)%\]$/);
  if (progressMatch) {
    return {
      name: 'progress',
      status: 'building',
      progress: parseInt(progressMatch[1]),
    };
  }

  return { name: 'unknown', status: 'unknown' };
}

// ── Error parsing (Buildroot format) ──

parseBuildrootError(line: string): BuildError {
  const patterns = [
    // Makefile error
    {
      pattern: /make\[(\d+)\]: \*\*\* (.*)/,
      parse: (m: RegExpMatchArray): BuildError => ({
        level: 'error',
        message: m[2],
        location: { file: 'Makefile', line: 0 },
        suggestion: 'Check for dependency or configuration errors',
      }),
    },
    // Configuration error
    {
      pattern: /Configuration file .* is not valid/,
      parse: (): BuildError => ({
        level: 'error',
        message: 'Invalid Buildroot configuration file',
        suggestion: 'Run make clean && make defconfig to reset the configuration',
      }),
    },
    // Missing dependency
    {
      pattern: / Missing: (.*)/,
      parse: (m: RegExpMatchArray): BuildError => ({
        level: 'error',
        message: `Missing dependency: ${m[1]}`,
        suggestion: 'Install the missing development tools',
      }),
    },
    // Compilation error
    {
      pattern: /error: (.*)/,
      parse: (m: RegExpMatchArray): BuildError => ({
        level: 'error',
        message: m[1],
        suggestion: 'Check the source code or the cross-compilation toolchain',
      }),
    },
  ];

  for (const { pattern, parse } of patterns) {
    const match = line.match(pattern);
    if (match) {
      return parse(match);
    }
  }

  return { level: 'error', message: line };
}

// rk3588Build.ts

export async function buildUBoot(config: UBootConfig): Promise<BuildStage> {
  const startTime = Date.now();

  // 1. Prepare the source
  await this.prepareUBootSource(config);

  // 2. Configure
  const configureResult = await this.runCommand(`
    cd ${config.sourceDir}/u-boot
    make CROSS_COMPILE=aarch64-linux-gnu- ${config.defconfig}
  `);

  if (!configureResult.success) {
    throw new BuildError('U-Boot configuration failed', configureResult.stderr);
  }

  // 3. Build
  const buildResult = await this.runCommand(`
    cd ${config.sourceDir}/u-boot
    make CROSS_COMPILE=aarch64-linux-gnu- -j${config.jobs}
  `, {
    env: {
      ...process.env,
      // Rockchip-specific environment variables
      RK_IDBLOADER: '1',          // Generate idbloader.img
      RK_CHIP: 'RK3588',
    },
    timeout: config.timeout || 600000, // 10 minutes
  });

  if (!buildResult.success) {
    throw new BuildError('U-Boot build failed', buildResult.stderr);
  }

  // 4. Generate idbloader.img
  const idbloaderPath = await this.runCommand(`
    cd ${config.sourceDir}/u-boot
    ./tools/mkimage -n rk3588 -T rksd -d ./u-boot-tpl.bin:./u-boot-spl.bin idbloader.img
  `);

  return {
    name: 'u-boot',
    status: 'success',
    duration: Date.now() - startTime,
    artifacts: {
      'idbloader.img': `${config.sourceDir}/u-boot/idbloader.img`,
      'u-boot.bin': `${config.sourceDir}/u-boot/u-boot.bin`,
    },
  };
}

// rk3588Build.ts

export async function buildKernel(config: KernelConfig): Promise<BuildStage> {
  const startTime = Date.now();

  // 1. Prepare the source
  await this.prepareKernelSource(config);

  // 2. Apply the Device Tree
  await this.applyDeviceTree(config);

  // 3. Configure
  await this.runCommand(`
    cd ${config.sourceDir}/kernel
    make ${config.defconfig}
  `);

  // 4. Build the kernel
  const buildResult = await this.runCommand(`
    cd ${config.sourceDir}/kernel
    make ${config.arch} CROSS_COMPILE=${config.crossCompile} -j${config.jobs}
  `, { timeout: config.timeout || 1800000 }); // 30 minutes

  if (!buildResult.success) {
    throw new BuildError('Kernel build failed', buildResult.stderr);
  }

  // 5. Build the device trees
  await this.runCommand(`
    cd ${config.sourceDir}/kernel
    make ${config.arch} CROSS_COMPILE=${config.crossCompile} dtbs
  `);

  // 6. Build the modules
  await this.runCommand(`
    cd ${config.sourceDir}/kernel
    make ${config.arch} CROSS_COMPILE=${config.crossCompile} modules -j${config.jobs}
  `);

  // 7. Package boot.img
  const bootImg = await this.createBootImage(config);

  return {
    name: 'kernel',
    status: 'success',
    duration: Date.now() - startTime,
    artifacts: {
      'Image': `${config.sourceDir}/kernel/arch/${config.arch}/boot/Image`,
      'boot.img': bootImg,
      'dtbs': `${config.sourceDir}/kernel/arch/${config.arch}/boot/dts/rockchip/rk3588*.dtb`,
    },
  };
}

// Create boot.img (contains kernel + dtb + ramdisk)
async function createBootImage(config: KernelConfig): Promise<string> {
  const bootDir = `${config.outputDir}/boot`;
  await fs.mkdir(bootDir, { recursive: true });

  // Copy the kernel and device tree
  await fs.copyFile(
    `${config.sourceDir}/kernel/arch/${config.arch}/boot/Image`,
    `${bootDir}/kernel`
  );

  await fs.copyFile(
    `${config.sourceDir}/kernel/arch/${config.arch}/boot/dts/rockchip/${config.dtb}`,
    `${bootDir}/rk3588.dtb`
  );

  // Generate boot.scr
  const bootScript = `
setenv bootargs "root=/dev/mmcblk0p4 rootwait earlyprintk console=ttyS2,1500000"
load mmc 0:4 0x600000 /boot/kernel
load mmc 0:4 0x400000 /boot/rk3588.dtb
booti 0x600000 - 0x400000
`;

  await fs.writeFile(`${bootDir}/boot.scr`, bootScript);
  await this.runCommand(`cd ${bootDir} && ./mkimage -C none -A arm64 -T script -d boot.scr boot.img`);

  return `${bootDir}/boot.img`;
}

export interface DTBGenerator {
  generateBaseDTS(project: ProjectModel): string;
  generateBoardDTS(project: ProjectModel): string;
  generateOverlay(bridgeSpec: BridgeSpec): string;
  compileDTS(dtsPath: string): string;
  mergeOverlays(baseDtb: string, overlays: string[]): string;
}

export function generateDeviceTree(
  project: ProjectModel,
  bridgeSpec?: BridgeSpec
): DeviceTreeFiles {
  const generator = new RK3588DTBGenerator();

  // 1. Generate the base DTS
  const baseDts = generator.generateBaseDTS(project);

  // 2. Generate the board DTS
  const boardDts = generator.generateBoardDTS(project);

  // 3. Generate the Bridge Spec overlay (if an FPGA interconnect exists)
  let overlayDts = '';
  if (bridgeSpec) {
    overlayDts = generator.generateOverlay(bridgeSpec);
  }

  // 4. Compile to DTB
  const baseDtb = generator.compileDTS(baseDts);
  const boardDtb = generator.compileDTS(boardDts);

  // 5. Merge overlays
  const mergedDtb = overlayDts
    ? generator.mergeOverlays(boardDtb, [overlayDts])
    : boardDtb;

  return {
    baseDts,
    boardDts,
    overlayDts,
    baseDtb,
    boardDtb,
    mergedDtb,
  };
}

  generateOverlay(bridgeSpec: BridgeSpec): string {
    const dts = [
      '// Bridge Spec Overlay - Auto-generated',
      '// FPGA ↔ SoC Interface Definition',
      '',
      '/ {',
      '  fragment@fpga-bridge {',
      '    target = <&amba>;',
      '    __overlay__ {',
      '',
    ];

    // Address mapping
    for (const addrMap of bridgeSpec.addressMaps) {
      dts.push('      // Address mapping');
      dts.push(`      fpga@${addrMap.fpgaBase.toString(16)} {`);
      dts.push('        compatible = "rockchip,fpga-bridge";');
      dts.push(`        reg = <0x0 ${addrMap.fpgaBase.toString(16)} ${addrMap.size}>;`);
      dts.push('        #address-cells = <0x1>;');
      dts.push('        #size-cells = <0x1>;');
      dts.push('');
      dts.push('        // FPGA internal registers');
      for (const reg of addrMap.registers) {
        dts.push(`        reg@${reg.offset.toString(16)} {`);
        dts.push(`          reg = <${reg.offset} ${reg.size}>;`);
        dts.push(`          // ${reg.name}: ${reg.description}`);
        dts.push('        };');
      }
      dts.push('      };');
      dts.push('    };');
    }

    // Interrupt routing
    if (bridgeSpec.interrupts.length > 0) {
      dts.push('');
      dts.push('    __overlay__ {');
      dts.push('      // Interrupt routing');
      for (const irq of bridgeSpec.interrupts) {
        dts.push(`      fpga-irq@${irq.gicNumber} {`);
        dts.push(`        compatible = "rockchip,fpga-irq";`);
        dts.push(`        interrupts = <GIC_SPI ${irq.gicNumber} IRQ_TYPE_LEVEL_HIGH>;`);
        dts.push(`        // Source: ${irq.source}`);
        dts.push('      };');
      }
      dts.push('    };');
    }

    dts.push('  };');
    dts.push('};');

    return dts.join('\n');
  }

  compileDTS(dtsPath: string): string {
    const dtbPath = dtsPath.replace('.dts', '.dtb');
    this.runCommand(`dtc -I dts -O dtb -o ${dtbPath} ${dtsPath}`);
    return dtbPath;
  }

  mergeOverlays(baseDtb: string, overlays: string[]): string {
    let current = baseDtb;
    for (const overlay of overlays) {
      const overlayDtb = overlay.replace('.dtsh', '.dtbo');
      this.runCommand(`dtc -I dts -O dtb -o ${overlayDtb} ${overlay}`);
      current = this.runCommand(
        `fdtapply ${current} ${overlayDtb}`
      );
    }
    return current;
  }
}

4.4 GPIO/Clock/Interrupt Resource Allocation

// resourceAllocator.ts

export interface ResourceAllocation {
  gpio: GPIOAllocation[];
  clocks: ClockAllocation[];
  interrupts: InterruptAllocation[];
}

export class RK3588ResourceAllocator {
  // Predefined architectural resources
  private static readonly ARCH_RESERVED = {
    // GPIO bank reservations
    gpio0: { used: ['PA0-PA7'], reserved: ['PB0-PB7'] },
    gpio1: { used: ['PA0-PA7'], reserved: [] },
    gpio2: { used: [], reserved: ['PC0-PC7'] },  // Used for camera

    // Interrupt reservations (GIC SPI)
    reservedIrqs: [32, 33, 34, 35],  // System interrupts

    // Clock reservations
    reservedClks: ['pll_npu', 'clk_npu'],
  };

  allocateGPIOA(project: ProjectModel): GPIOAllocation[] {
    const allocations: GPIOAllocation[] = [];

    for (const pin of project.hardware.gpioPins) {
      // Check for conflicts with architectural reservations
      const isReserved = RK3588ResourceAllocator.ARCH_RESERVED.gpio0.reserved
        .some(r => r === pin.pin);

      if (isReserved) {
        throw new Error(`GPIO pin ${pin.pin} is reserved by architecture`);
      }

      allocations.push({
        pin: pin.pin,
        function: pin.function,
        direction: pin.direction,
        pull: pin.pull || 'none',
      });
    }

    return allocations;
  }

  allocateInterrupts(project: ProjectModel): InterruptAllocation[] {
    const allocations: InterruptAllocation[] = [];

    // IRQ numbers start here (at 64, reserving the first 64)
    let nextIrq = 64;

    for (const irq of project.hardware.interrupts) {
      allocations.push({
        source: irq.source,
        gicNumber: nextIrq,
        type: irq.type,  // 'level' | 'edge'
        polarity: irq.polarity || 'high',  // 'high' | 'rising' etc.
      });
      nextIrq++;
    }

    return allocations;
  }

  allocateClocks(project: ProjectModel): ClockAllocation[] {
    const allocations: ClockAllocation[] = [];

    // Fixed clock allocations
    const fixedClocks = [
      { name: 'clk_uart2', freq: 24000000, source: 'xin24m' },
      { name: 'clk_gmac0', freq: 125000000, source: 'gmac_clkin' },
      { name: 'clk_sdmmc', freq: 200000000, source: 'cpll' },
    ];

    for (const clk of fixedClocks) {
      allocations.push(clk);
    }

    // Dynamic clock allocations
    for (const dynamicClk of project.hardware.clocks) {
      allocations.push({
        name: dynamicClk.name,
        freq: dynamicClk.frequency,
        source: dynamicClk.source,
      });
    }

    return allocations;
  }

export interface FlashConfig {

}

export class RK3588Flash {
  private rkTool: string;
  private device: string;

  constructor(config: { rkToolPath: string; device?: string }) {
    this.rkTool = config.rkToolPath;
    this.device = config.device || '/dev/ttyUSB0';
  }

  async flash(firmware: FirmwareBinary): Promise<FlashResult> {
    const result: FlashResult = {
      success: false,
      partitions: [],
      error: undefined,
    };

    try {
      // 1. Detect Maskrom mode
      await this.detectMaskrom();

      // 2. Download the MiniLoader
      await this.downloadLoader();

      // 3. Write the partition table
      await this.writeParameter(firmware.parameter);

      // 4. Download the firmware
      for (const partition of firmware.partitions) {
        await this.downloadPartition(partition);
        result.partitions.push({
          name: partition.name,
          offset: partition.offset,
          size: partition.size,
          path: partition.file,
          checksum: await this.calculateChecksum(partition.file),
        });
      }

      // 5. Verify and reboot
      await this.verifyAndReboot();

      result.success = true;
    } catch (error) {
      result.success = false;
      result.error = error.message;
    }

    return result;
  }

  // ── Maskrom mode detection ──

  async detectMaskrom(): Promise<void> {
    const result = await this.runCommand(`
      ${this.rkTool} list
    `);

    if (!result.stdout.includes('Maskrom')) {
      throw new Error(
        'The device is not in Maskrom mode. Please:\n' +
        '1. Power off\n' +
        '2. Hold the MASKROM button\n' +
        '3. Power on\n' +
        '4. Release the button'
      );
    }
  }

  // ── LOADER download ──

  async downloadLoader(): Promise<void> {
    console.log('Downloading MiniLoader...');

    const result = await this.runCommand(`
      ${this.rkTool} dnl ${this.loaderPath}
    `, { timeout: 60000 });

    if (!result.success) {
      throw new Error(`Loader download failed: ${result.stderr}`);
    }

    // Wait for the device to enter loader mode
    await this.waitForLoaderMode();
  }

  // ── Partition table write ──

  async writeParameter(parameter: string): Promise<void> {
    console.log('Writing parameter...');

    const result = await this.runCommand(`
      cd ${this.firmwareDir}
      ${this.rkTool} down ${parameter}
    `);

    if (!result.success) {
      throw new Error(`Parameter write failed: ${result.stderr}`);
    }
  }

  // ── Partition write ──

  async downloadPartition(partition: PartitionInfo): Promise<void> {
    console.log(`Downloading ${partition.name}...`);

    const result = await this.runCommand(`
      ${this.rkTool} up ${partition.name} ${partition.file}
    `, { timeout: partition.size / 1024 / 10 }); // ~10MB/s

    if (!result.success) {
      throw new Error(`Partition ${partition.name} write failed: ${result.stderr}`);
    }
  }

  // ── Verify and reboot ──

  async verifyAndReboot(): Promise<void> {
    console.log('Verifying and rebooting...');

    const result = await this.runCommand(`
      ${this.rkTool} verif
    `);

    if (!result.success) {
      throw new Error(`Verification failed: ${result.stderr}`);
    }

    // Reboot the device
    await this.runCommand(`${this.rkTool} reboot`);
  }

  // ── Utility functions ──

  private async waitForLoaderMode(timeout = 30000): Promise<void> {
    const start = Date.now();
    while (Date.now() - start < timeout) {
      const result = await this.runCommand(`${this.rkTool} list`);
      if (result.stdout.includes('Loader')) {
        return;
      }
      await this.sleep(500);
    }
    throw new Error('Timed out waiting for Loader mode');
  }

  private async calculateChecksum(file: string): Promise<string> {
    const result = await this.runCommand(`md5sum ${file}`);
    return result.stdout.split(' ')[0];
  }
}

// parameter.txt format
export function generateParameterTxt(
  partitions: PartitionConfig[],
  version: string
): string {
  const lines = [
    `FIRMWARE_VER: ${version}`,
    `MAGIC: 0x4F524B50`,
    `CMDLINE: mtdparts=rk29xxnand:`,
  ];

  const mtdParts = partitions.map(p => {
    const sizeHex = p.size.startsWith('0x')
      ? parseInt(p.size).toString(16)
      : p.size;
    return `${p.name}@0x${parseInt(p.offset).toString(16)}(${p.name})`;
  });

  lines.push('    ' + mtdParts.join(',\\');
  lines.push('');

  return lines.join('\n');
}

// serialDebug.ts

export interface SerialConfig {
  port: string;           // '/dev/ttyUSB0' or 'COM3'
  baudRate: number;       // 1500000 (RK3588 default)
  dataBits: 8;
  stopBits: 1;
  parity: 'none';
}

export class SerialDebugger {
  private port: SerialPort;
  private reader: ReadableStreamDefaultReader;
  private logBuffer: SerialLog[] = [];

  async connect(config: SerialConfig): Promise<void> {
    this.port = new SerialPort({
      path: config.port,
      baudRate: config.baudRate,
      dataBits: config.dataBits,
      stopBits: config.stopBits,
      parity: config.parity,
    });

    this.reader = this.port.read(ttyBuffer).getReader();
  }

  async readLogs(duration = 5000): Promise<SerialLog[]> {
    const logs: SerialLog[] = [];
    const startTime = Date.now();

    while (Date.now() - startTime < duration) {
      const { value, done } = await this.reader.read();

      if (done) break;

      const line = new TextDecoder().decode(value);
      logs.push({
        timestamp: Date.now(),
        content: line,
        level: this.parseLogLevel(line),
      });

      this.logBuffer.push(logs[logs.length - 1]);
    }

    return logs;
  }

  parseLogLevel(line: string): 'info' | 'warn' | 'error' | 'debug' {
    if (line.includes('[    0.000000]') || line.includes('Starting kernel')) {
      return 'info';
    }
    if (line.includes('WARNING') || line.includes('warn')) {
      return 'warn';
    }
    if (line.includes('ERROR') || line.includes('BUG') || line.includes('Panic')) {
      return 'error';
    }
    return 'debug';
  }

  // Keep listening and stream logs in real time
  async *streamLogs(): AsyncGenerator<SerialLog> {
    while (true) {
      const { value, done } = await this.reader.read();
      if (done) break;

      const line = new TextDecoder().decode(value);
      const log: SerialLog = {
        timestamp: Date.now(),
        content: line,
        level: this.parseLogLevel(line),
      };

      this.logBuffer.push(log);
      yield log;
    }
  }
}

// adbDebug.ts

export interface ADBDevice {
  serial: string;
  state: 'device' | 'offline' | 'unauthorized';

export class ADBManager {
  private adbPath: string;

  constructor(adbPath = 'adb') {
    this.adbPath = adbPath;
  }

  async getDevices(): Promise<ADBDevice[]> {
    const result = await this.runCommand(`${this.adbPath} devices -l`);
    const devices: ADBDevice[] = [];

    for (const line of result.stdout.split('\n').slice(1)) {
      if (!line.trim()) continue;

      const parts = line.split(/\s+/);
      devices.push({
        serial: parts[0],
        state: parts[1] as ADBDevice['state'],
        product: this.extractValue(parts, 'product'),
        model: this.extractValue(parts, 'model'),
        device: this.extractValue(parts, 'device'),
      });
    }

    return devices;
  }

  async shell(command: string): Promise<string> {
    const result = await this.runCommand(`${this.adbPath} shell "${command}"`);
    return result.stdout;
  }

  async pull(remotePath: string, localPath: string): Promise<void> {
    await this.runCommand(`${this.adbPath} pull ${remotePath} ${localPath}`);
  }

  async push(localPath: string, remotePath: string): Promise<void> {
    await this.runCommand(`${this.adbPath} push ${localPath} ${remotePath}`);
  }

  async getDmesg(): Promise<string[]> {
    const output = await this.shell('dmesg');
    return output.split('\n').filter(line => line.trim());
  }

  async getKernelPanic(): Promise<KernelPanicInfo | null> {
    const dmesg = await this.getDmesg();

    // Look for kernel panic information
    const panicLines: string[] = [];
    let inPanic = false;

    for (const line of dmesg) {
      if (line.includes('Kernel panic')) {
        inPanic = true;
      }
      if (inPanic) {
        panicLines.push(line);
        if (line.includes('---[ end trace')) {
          break;
        }
      }
    }

    if (panicLines.length === 0) {
      return null;
    }

    return {
      fullLog: panicLines.join('\n'),
      timestamp: this.extractTimestamp(panicLines[0]),
      reason: this.extractPanicReason(panicLines),
      callTrace: this.extractCallTrace(panicLines),
    };
  }

  private extractPanicReason(lines: string[]): string {
    for (const line of lines) {
      if (line.includes('not syncing')) {
        const match = line.match(/not syncing: (.+)$/);
        return match ? match[1] : 'Unknown';
      }
    }
    return 'Unknown';
  }

  private extractCallTrace(lines: string[]): string[] {
    const trace: string[] = [];
    let inTrace = false;

    for (const line of lines) {
      if (line.includes('Call trace:') || line.includes('Stack:')) {
        inTrace = true;
        continue;
      }
      if (inTrace && line.match(/^\s*0x[0-9a-f]+/)) {
        trace.push(line.trim());
      }
      if (inTrace && line.match(/^\s*--- end trace/)) {
        break;
      }
    }

    return trace;
  }
}

// kernelPanicAnalyzer.ts

export interface KernelPanicAnalyzer {
  analyze(panicInfo: KernelPanicInfo): PanicAnalysis;
  suggestFixes(analysis: PanicAnalysis): FixSuggestion[];
}

export interface PanicAnalysis {
  type: PanicType;
  severity: 'critical' | 'high' | 'medium';
  rootCause: string;
  affectedComponent: string;
  stackTrace: AnalyzedStackTrace[];
}

export interface FixSuggestion {
  description: string;
  command?: string;
  configChange?: ConfigChange;
  confidence: number;  // 0-1
}

export class RK3588PanicAnalyzer implements KernelPanicAnalyzer {
  // Panic type recognition patterns
  private readonly PANIC_PATTERNS = [
    {
      type: 'oom' as PanicType,
      pattern: /Out of memory.*LPJ/,
      severity: 'critical',
      rootCause: 'Out of memory',
      suggestedFixes: [
        { description: 'Increase the zram size', command: 'echo 50% > /sys/block/zram0/disksize' },
        { description: 'Reduce init services', confidence: 0.8 },
        { description: 'Increase DDR capacity or enable swap', confidence: 0.6 },
      ],
    },
    {
      type: 'null_pointer' as PanicType,
      pattern: /BUG: unable to handle kernel NULL pointer dereference/,
      severity: 'critical',
      rootCause: 'NULL pointer dereference',
      suggestedFixes: [
        { description: 'Check the driver load order', confidence: 0.7 },
        { description: 'Update the kernel or driver version', confidence: 0.5 },
      ],
    },
    {
      type: 'watchdog' as PanicType,
      pattern: /watchdog.*timer didn't stop/,
      severity: 'high',
      rootCause: 'Watchdog timeout, system hang',
      suggestedFixes: [
        { description: 'Increase the watchdog timeout', configChange: { kernel: 'CONFIG_WATCHDOG_TIMEOUT=30' } },
        { description: 'Check the system load', confidence: 0.6 },
      ],
    },
    {
      type: 'fs' as PanicType,
      pattern: /VFS: Unable to mount root fs/,
      severity: 'critical',
      rootCause: 'Root filesystem mount failed',
      suggestedFixes: [
        { description: 'Check the rootfs path in boot.img', confidence: 0.9 },
        { description: 'Verify the rootfs image integrity', command: 'sha256sum rootfs.squashfs' },
        { description: 'Check the kernel cmdline root parameter', confidence: 0.8 },
      ],
    },
  ];

  analyze(panicInfo: KernelPanicInfo): PanicAnalysis {
    for (const pattern of this.PANIC_PATTERNS) {
      if (pattern.pattern.test(panicInfo.fullLog)) {
        return {
          type: pattern.type,
          severity: pattern.severity,
          rootCause: pattern.rootCause,
          affectedComponent: this.extractAffectedComponent(panicInfo),
          stackTrace: this.analyzeStackTrace(panicInfo.callTrace),
        };
      }
    }

    return {
      type: 'unknown',
      severity: 'high',
      rootCause: 'Unknown cause',
      affectedComponent: 'unknown',
      stackTrace: [],
    };
  }

  suggestFixes(analysis: PanicAnalysis): FixSuggestion[] {
    for (const pattern of this.PANIC_PATTERNS) {
      if (pattern.type === analysis.type) {
        return pattern.suggestedFixes;
      }
    }
    return [];
  }

  private analyzeStackTrace(callTrace: string[]): AnalyzedStackTrace[] {
    return callTrace.map(addr => ({
      address: addr,
      // Can be further resolved to symbols with addr2line
      symbol: this.resolveSymbol(addr),
    }));
  }

  private resolveSymbol(addr: string): string {
    // Call arm-none-eabi-addr2line or aarch64-linux-gnu-addr2line
    // return runCommand(`aarch64-linux-gnu-addr2line -e vmlinux ${addr}`);
    return addr;
  }
}

9. Adapter Contract Hardening

9.1 Profile-Driven, Not RK3588 Hard-Coding

RK3588Adapter must consume an immutable BspProfile: board/carrier revision, BSP manifest, build entry points, component commits, container digest, toolchain, defconfig, base DTS, loaders, partition layout, artifact rules, and verified capabilities. The adapter never guesses defconfigs, DT labels, GPIOs, or flash offsets; when something is missing, it fails during preflight.

interface BspProfile {
  schemaVersion: '1';
  id: string;
  boardRevision: string;
  bsp: { manifest: string; commit: string; family: 'rockchip-linux' | 'vendor-fork' };
  environment: { containerDigest: string; toolchainTriple: string; toolchainSha256: string };
  commands: { configure: CommandSpec; build: Record<BuildStageName, CommandSpec> };
  boot: { loaderSha256: string; partitionLayoutSha256: string };
  deviceTree: { baseDtb: string; permittedOverlays: string[] };
  capabilities: Record<string, 'verified' | 'experimental' | 'unsupported'>;
}

Commands must be executed as argument arrays, never by splicing user input through a shell; set the cwd, an environment-variable allowlist, timeouts, and cancellation signals, and store stdout/stderr verbatim. Build output goes into a dedicated directory; modifying files in the SDK source tree that the user did not declare is forbidden.

9.2 Upgrade the Interface from Synchronous Pseudocode to an Async, Cancellable Contract

Split the generic VendorAdapter's build() into preflight/plan/execute/collect, and make program() and debug() optional capabilities, instead of forcing SoC adapters to return fake data for FPGA timing interfaces.

interface AdapterCapabilities { build: true; package: boolean; flash: boolean; debug: boolean; timing: boolean }
interface VendorAdapterV2 {
  readonly id: string;
  readonly capabilities: AdapterCapabilities;
  preflight(ctx: OperationContext): Promise<Diagnostic[]>;
  plan(project: ProjectModel, ctx: OperationContext): Promise<BuildPlan>;
  execute(plan: BuildPlan, ctx: OperationContext): AsyncIterable<BuildEvent>;
  collect(runId: string, ctx: OperationContext): Promise<BuildReport>;
  flash?(request: FlashRequest, ctx: OperationContext): AsyncIterable<FlashEvent>;
}

OperationContext contains at least the workspace, an AbortSignal, a log scrubber, an execution policy, and approval tokens. BuildReport records the stage DAG, command digests, exit codes, durations, peak resources, diagnostics, artifact SHA-256s, config/source identity, and log locations; success must be derived from all required stages succeeding and artifact verification passing — not from the last process exit code alone.

9.3 Safety Boundaries of Device Tree Generation

By default, the adapter does not generate a board DTS from scratch; instead: select the profile's verified base DTS → generate a minimal overlay/controlled patch → compile with dtc → schema/semantic validation → merged verification against the base DT → output a diff. The PCIe RC's DT covers the controller, PHY, clocks/resets, and the board-level PERST#; the FPGA Endpoint is enumerated from the PCI bus and drivers bind by PCI ID. All node labels, clock IDs, reset IDs, GPIOs, and ranges in the examples are board/BSP-specific placeholders and must not be shipped without verification against the target BSP.

The Bridge Spec must simultaneously produce: the FPGA register header file, the Linux UAPI/driver description, the device tree patch (applicable items only), the protocol version, and an ABI hash. Address, width, alignment, endianness, cache coherency, DMA mask/IOMMU, IRQ semantics, reset timing, and error recovery are all mandatory or explicitly not-applicable; maintaining multiple hand-written register tables in parallel is forbidden.

9.4 Transaction and Permission Model for Flash

Flash is a high-risk, standalone capability. The flow is discover → identify → snapshot layout → validate images → dry-run plan → explicit approval → write → verify → reboot/health-check. Requests must carry a stable device identifier, the expected SoC/mode, the profile ID, and image hashes; multiple devices or an identity mismatch means rejection. Using a serial device path as rkdeveloptool's device selector is forbidden, as are default erases and hard-coded LBAs. Whole-disk images, bootloaders, GPT, and user-data partitions carry different risk levels.

9.6 Design Assumptions Explicitly Corrected

  • The RGMII delay must be borne by exactly one place or an explicit combination of MAC, PCB, or PHY; phy-mode must match the hardware. fixed-link and "configure the internal PHY over MDIO" are two different models and must not both be described as the default.
  • The MAC address source is a board-level policy (OTP/NVMEM, bootloader injection, production configuration); do not blindly assume that the RK3588 OTP already holds a usable unique address.
  • Combo PHY, PCIe/SATA/USB3 multiplexing, MIPI DPHY sharing, and GPIO availability all depend on the package, schematic, and BSP; the appendix's "no conflict" can only be a candidate pending verification, not a design commitment.
  • Artifacts such as update.img, trust.img, uboot.img, and FIT/Android boot images are decided by the BSP packaging scheme; the adapter describes the artifact graph through a profile and does not fix any particular naming.

9.7 Testing Strategy

Unit tests cover the profile schema, command escaping, log parsing, DT/Bridge generation, and diagnostic deduplication; contract tests use a fake toolchain to verify event sequences, cancellation, timeouts, and failure propagation; integration tests run clean/incremental builds against a locked BSP; HIL tests manage boards with exclusive locks, capture serial output, and verify cold boot, flash recovery, and Bridge stress. The minimal key of the release compatibility matrix is adapter + profile + BSP commit + board revision + boot media.
