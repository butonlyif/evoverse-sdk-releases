RK3588 Minimal Cross-Compilation Environment (Windows + WSL2)

RK3588 Minimal Cross-Compilation Environment (Windows + WSL2)

A minimal RK3588 AArch64 cross-compilation baseline set up for vibe coding. It does not include the full SDK build/flash chain; that part must wait until the target board + BSP are locked down (see RK3588-开发环境调研报告.md §8.x).

1. Usage

# 进入 WSL Ubuntu
wsl -d Ubuntu-22.04

# 加载本目录的环境脚本
source /mnt/d/work/trae_projects/RK3588/.scratch/rk3588-dev-env.sh

# 跨编 + 冒烟测试
cd /mnt/d/work/trae_projects/RK3588/.scratch
aarch64-linux-gnu-gcc -O2 -Wall -static hello.c -o hello
qemu-aarch64-static ./hello    # 应输出 hello from aarch64 (uid=...)

# DTS 编译/反编译
dtc -I dts -O dtb -o probe.dtb probe.dts

2. What Is Installed

Component Version Purpose
Ubuntu 22.04.5 LTS WSL2 distro Linux build environment
gcc-aarch64-linux-gnu / g++-aarch64-linux-gnu Ubuntu 11.4.0 AArch64 cross compilers
libc6-dev-arm64-cross 2.35 cross3 Cross-compilation C library + sysroot
device-tree-compiler (dtc) 1.6.1 DTS ↔ DTB
qemu-user-static 6.2.0 Run AArch64 ELF smoke tests on the host
python3 / python3-venv 3.10.12 RKNN / general scripting
numpy / onnx 1.26.4 / 1.22.0 Inside the venv /root/rknn-venv

3. Verified (End to End)

  • ✅ aarch64-linux-gnu-gcc -static hello.c produces an ELF 64-bit LSB ARM aarch64 binary
  • ✅ qemu-aarch64-static ./hello runs on the host
  • ✅ Bidirectional DTS↔DTB compilation with dtc
  • ✅ The cross-compilation sysroot is discoverable by host pkg-config via /usr/aarch64-linux-gnu/lib/pkgconfig

4. Not Done Yet / Deferred Until the Target Board + BSP Are Decided

  1. RKNN Toolkit2 wheel installation — must wait until the board/BSP and NPU driver versions are fixed, to avoid numpy/librknn version conflicts
  2. rkdeveloptool — the flashing toolchain; needs a USB device passthrough solution (WSL2 does not pass through by default)
  3. Full BSP containerization — the rk3588-dev Docker image from survey report §3.3.2; only meaningful once the board is locked
  4. build-manifest.json contract — survey report §8.2; generate it after the first board is chosen
  5. Board DTS overlay — survey report §5.x; the vendor DTS is required before an overlay can be drafted
  6. kernel module cross build — requires pulling the target kernel headers from the vendor BSP as the sysroot, not the current venv

5. Known Gotchas

  • aarch64-linux-gnu-pkg-config is not in the Ubuntu repositories; use PKG_CONFIG_LIBDIR=/usr/aarch64-linux-gnu/lib/pkgconfig + host pkg-config
  • The current default WSL2 distro is still docker-desktop; switch with wsl -s Ubuntu-22.04
  • WSL2 does not pass USB Maskrom devices through by default; before flashing, verify device reachability on the Windows host or set up usbipd
