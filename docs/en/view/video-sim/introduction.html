Video Sim Platform Introduction

Video Sim Platform Introduction

EvoVerse SDK v1.0.0 · Video Sim v1.0.1 · 2026-09-30

One-sentence definition

Video Sim (also known as the VIP simulation and verification platform) is EvoVerse's video IP sub-product: feed an image in, pass it through your RTL module, get an image out, and be told how well the processing worked.

The problems it solves

Video IP development has four recurring pain points:

Pain point How Video Sim answers it
Stuffing real images into an RTL simulation means writing a pile of hex-conversion scripts Image/video → simulation stimulus is fully automatic; the output is hex that $readmemh can read
When the simulation finishes you can only stare at waveforms, with no intuitive way to judge image quality Result restoration: hex is converted back to PNG/MP4 automatically, so you see the effect directly
No objective verdict on whether the RTL implementation is correct Golden-reference comparison: a Python reference model reproduces the RTL fixed-point arithmetic bit for bit and declares PASS / FAIL automatically
Tuning one parameter gives you no sense of how much it matters Multi-dimensional quality analysis: sharpness, white balance, PSNR, histogram, and Gamma curve, each in a pop-up panel of its own

Who it is for

  • FPGA verification engineers — image-level PASS/FAIL verdicts for video IPs
  • Research students — learning video-processing algorithms and verifying RTL implementations
  • IP developers — chaining algorithm → RTL → simulation → golden reference → regression testing into one complete loop

Relationship to the EvoVerse SDK

Scenario Recommended tool
FPGA board-level verification (programming, timing, debug) Use EvoVerse SDK (the evoverse-sdk VSIX)
Algorithm / image-level verification (no board, no synthesis) Use Video Sim (embedded in the evoverse-sdk VSIX)

The EvoVerse SDK already embeds the same Video Sim functionality (entry command evoverse.simIsp); installing the SDK is all it takes—no separate installation is needed.

Core capabilities

  • Image/video → simulation stimulus — automatic conversion to Verilog $readmemh hex
  • One-click simulation — iverilog compile + run + result collection, fully automatic
  • Result restoration — simulation output hex restored automatically to PNG/MP4
  • Golden-reference comparison — bit-for-bit reproduction by a Python reference model, with an automatic PASS / FAIL verdict
  • 6-part quality analysis — PSNR · sharpness · white balance · histogram · difference heatmap · Gamma curve
  • 9 test patterns — ramps / color blocks / checkerboards / noise / dead pixels and more, for systematic verification
  • DDR frame buffer — AXI4 DDR model + ping-pong double slots (VIP08)
  • Vibe Coding — describe it in natural language → RTL + golden model + TB + regdef generated automatically (VIP09)
  • Regression testing — make regression runs every snapshot in one shot (VIP10)

Toolchain

iverilog + Python 3.11+ + Pillow / NumPy / OpenCV

Consistent across platforms: macOS / Linux / Windows all work; on Windows GNU Make is not needed—the pure-Python scripts/sim.py orchestrates everything.
