                                  [--params PARAMS] [--project PROJECT]
                                  [--force]
                                  id

positional arguments:
  id                 工程 ID 或 SoC 实例名

options:
  -h, --help         show this help message and exit

evoverse design

检查 Efinity 原生 Interface Designer 文件（DesignAPI）

usage: evoverse design [-h]
                       {capabilities,create-patch,delete-patch,inspect,validate,export-isf,auto-assign,preview-isf,property-patch}
                       ...

positional arguments:
  {capabilities,create-patch,delete-patch,inspect,validate,export-isf,auto-assign,preview-isf,property-patch}
    capabilities        列出块类型、版本、I/O bank 及可选资源
    create-patch        创建并验证接口实例，然后导出原生 ISF
    delete-patch        删除并验证接口实例，然后导出原生 ISF
    inspect             检查实例、属性及已分配资源
    validate            运行原生 DesignAPI DRC
    export-isf          将 peri.xml 设计导出为 Efinity 原生 ISF
    auto-assign         预览或显式导出原生资源分配
    preview-isf         将候选原生 ISF 应用到临时设计并显示差异
    property-patch      单独验证属性编辑并导出原生 ISF

options:
  -h, --help            show this help message and exit
