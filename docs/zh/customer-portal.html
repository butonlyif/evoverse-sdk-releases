ARCHITECTURE

一套 SDK，双芯片融合：Efinity FPGA + RK3588 SoC

宿主编辑器与 SDK Core 之间、Core 与各 Adapter 之间都是显式契约：上层只做编排与呈现， 工具链能力由 Adapter 提供并按需组合安装。FPGA 侧负责视频通路、RTL 与时序收敛，SoC 侧负责 BSP 交叉编译、固件基线与 NPU/LLM 推理——两侧共享同一条证据链，后续可接入更多目标平台。 分层细节见 SDK 详细说明。
