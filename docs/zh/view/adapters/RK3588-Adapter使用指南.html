RK3588 Adapter 使用指南

RK3588 Adapter 使用指南

版本：v1.0　适用 SDK 版本: v1.0.0 更新日期：2026-09-30

RK3588 Adapter 为 Rockchip RK3588 SoC 提供软件构建能力：BSP Profile 校验、U-Boot / Kernel / Rootfs 四阶段交叉编译、固件打包与产物校验。安装方式见 SDK 详细说明。

当前状态：构建与打包流程已完成并通过集成测试，首个 BUILD_READY 固件基线已于 2026-09-24 发布到 Catalog（boards/ws-e2/carriers/rk3588j-evm/baselines/ws-e2-rk3588j-minimal，catalog v0.9.3）。尚未在真实目标板上完成验证，烧录（Flash）与设备调试（Debug）暂不支持，界面会明确显示原因，不提供不可用按钮。

1. 环境要求

项目 要求
核心扩展 evoverse-sdk 同版本（必装，先于本 Adapter）
交叉工具链 aarch64-linux-gnu-gcc（Buildroot 集成）、dtc、mkimage
BSP Profile 工作区内 BSP Profile JSON（见 §3），声明工具链与 BSP 版本锁定

工具链版本由 BSP Profile 的 environment 段（containerDigest / toolchainTriple / toolchainSha256）锁定；preflight 阶段做哈希校验，不匹配即阻塞构建。

2. Workbench 八 Tab

打开方式：RK3588: Open Workbench。

Tab 功能 状态
Overview 构建流程链、G0/G1 门控状态、阻塞项、最近构建 可用
Board BSP manifest/commit、容器与工具链 digest（SHA-256 只读） 只读
Build 四阶段构建、实时输出、取消 可用
Firmware Package manifest、产物文件大小/SHA-256 只读
Boot Bootloader 配置只读视图 只读
Device Tree Device Tree 文件浏览 只读
Software 应用程序管理 占位
Debug 串口/ADB/SSH/HIL 调试 不支持（显示原因说明）

3. BSP Profile

RK3588 Adapter 不使用 VS Code settings 配置；全部配置载体是工作区内的 BSP Profile JSON（schema：catalog/soc/rk3588/profiles/bsp-profile.schema.json）。

查找顺序（取第一个命中）：

  1. <workspace>/evoverse-rk3588-profile.json
  2. <workspace>/.evoverse/rk3588-profile.json
  3. <workspace>/profile.json

Profile 内容分块：

  • bsp — manifest 地址 + commit 锁定（rockchip-linux 家族）
  • environment — 容器/工具链哈希锁定
  • boot — bootloader 与分区表哈希
  • 四阶段 commands（参数数组 + 超时）与 artifacts
  • capabilities — 声明 build / package / flash / debug 支持状态

4. 构建流程

四阶段流水线，每阶段可独立执行或全量执行，随时可取消：

G0 Preflight（Profile 哈希与路径校验）
   ↓
U-Boot → Kernel → Rootfs（Buildroot）→ Package（打包 update.img）
  • 命令以参数数组执行（无 shell 拼接），路径校验防逃逸
  • 产出 build-report.json + events.jsonl + 各产物 SHA-256
  • 刷新或重开后从报告文件恢复状态

构建产物在 Firmware Tab 核对：文件清单、大小、SHA-256。

5. 与 FPGA 工程的关系

在 FPGA + SoC 系统级设计中，RK3588 Adapter 承担 SoC 侧实现。跨芯片接口（PCIe / RGMII / MIPI / GPIO Bridge Spec）、Device Tree Overlay 生成属于后续阶段，当前版本未提供。

6. 命令清单

命令 功能
RK3588: Open Workbench 打开 RK3588 八 Tab 工作台

其余操作（preflight、分阶段构建、打包、取消、报告）通过 Workbench Build Tab 按钮触发。

7. 已知边界

  • Flash（烧录）：未实现。规划路径为 Maskrom 检测 → Loader 下载 → 分区写入 → 校验（rkdeveloptool）
  • Debug（串口/ADB/SSH/HIL）：未实现。规划含串口日志（默认 1500000 波特率）、ADB 管理、Kernel Panic 解析
  • Device Tree 生成：未实现（Board DTS / Bridge Overlay / 资源分配）
  • 已在真实目标板验证、量产烧录、Android/Yocto 支持不在当前版本范围
