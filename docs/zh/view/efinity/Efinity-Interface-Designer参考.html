Interface Designer 参考

Efinity Interface Designer 参考

版本: v1.0 | 基于 Efinity 2026.1 (UG-TiINTF-v1.0)

1. 概述

Efinity Interface Designer 是 Efinity 软件中用于构建 FPGA 外围接口（periphery）的 GUI 工具。它独立于核心逻辑设计，专注于配置 GPIO、LVDS、PLL、MIPI、DDR 等硬件块。

定位： - Efinity 主窗口 → 设计核心逻辑部分 - Interface Designer → 设计外围接口部分

启动方式：

efinity_pt.bat        # Windows
efinity_pt.sh         # Linux

来源: C:\Efinity\2026.1\pt\doc\topics\hlp-id-intro.html

2. 架构

Interface Designer 基于 Python 插件架构：

pt/
├── bin/
│   ├── api_service/      # API 服务层（设计、设备、资源）
│   ├── common_device/     # 通用设备逻辑（GPIO、Quad、属性、规则）
│   ├── common_gui/        # 通用 GUI 组件（builder、validator、viewer）
│   ├── design/            # 设计数据库（db.py、db_item.py、service.py）
│   ├── device/            # 设备数据库（clocks、io_info、package、service.py）
│   ├── main_gui/          # 主窗口 GUI
│   ├── res_asg/           # 资源分配器
│   ├── pin_browser/       # Pin 浏览器
│   ├── pkg_gui/           # 封装规划器
│   ├── schema/            # XML Schema 定义（40+ XSD 文件）
│   ├── writer/            # 输出文件生成器（pinout、timing、periphery）
│   ├── efx_run_pt_*.py    # CLI 入口脚本
│   └── engine.py          # 核心引擎
├── db/
│   ├── die/               # 裸片定义（block_models/*.xml）
│   └── resource/          # 设备资源数据库（.db 文件）
└── config.ini             # 配置文件

3. 支持的接口块 (Interface Blocks)

3.1 设备设置 (Device Settings)

块 说明
Configuration 配置模式（Active/Passive）、SPI Flash 类型等
I/O Banks I/O Bank 电压、Dynamic Voltage Support
Clock Networks 全局/区域时钟网络、动态时钟复用器
SEU Detection 单粒子翻转检测（Titanium/Topaz）
User Status Pin 用户状态引脚

3.2 IO 接口

块 支持器件 说明
GPIO All 通用 IO，支持 HVIO/HSIO、DDIO、Serializer/Deserializer
LVDS All 低压差分信号，TX/RX、GCLK/RCLK/PHYCLK
MIPI D-PHY Titanium/Topaz MIPI D-PHY TX/RX
MIPI CSI-2 Trion MIPI CSI-2 摄像头接口
MIPI Lane Titanium/Topaz MIPI Lane 配置

3.3 存储器接口

块 支持器件 说明
DDR All DDR2/DDR3/LPDDR3 DRAM
HyperRAM Titanium HyperRAM 存储器
SPI Flash Titanium/Trion SPI Flash 接口

PMA Direct Titanium/Topaz 直接 PMA 访问

3.5 时钟和系统

4. GUI 工作流程

4.1 设计接口

  1. 选择器件和封装
  2. 创建接口块（Create Block → 选择类型）
  3. 配置块参数（PLL 频率、GPIO 方向等）
  4. 分配引脚（Resource Assigner 或 Package Planner）
  5. 运行设计检查（Design Check）
  6. 生成约束文件（Generate Constraint Files）

4.2 资源分配器 (Resource Assigner)

  • Resource View：查看所有已分配资源
  • Import/Export：导入导出 GPIO 分配（CSV 格式或 ISF 格式）
  • GPIO CSV：批量 GPIO 配置

4.3 封装规划器 (Package Planner)

  • 可视化芯片封装引脚图
  • 拖放式引脚分配
  • 按 Bank 过滤
  • 排除特定引脚/Bank
  • 支持明/暗主题

6. ISF (Interface Scripting File) vs GUI

6.1 GUI 方式（Interface Designer）

  • 图形化操作，适合交互式设计
  • 所见即所得
  • 适合小型到中型引脚数量的设计
  • 支持拖放引脚分配

6.2 ISF 脚本方式

  • Python 脚本描述接口配置
  • 适合批量操作（大量 GPIO）
  • 适合设计复用和跨板移植
  • 支持版本控制（文本文件）
  • 可导出 -> 修改 -> 重新导入

ISF 格式示例：

# Efinity Interface Configuration
# Version: 2020.M.138

# 创建 GPIO 实例
design.create_output_gpio("Fled", 3, 0)
design.create_inout_gpio("Sled", 3, 0)
design.create_clockout_gpio("Oclk_out")
design.create_pll_input_clock_gpio("pll_clkin")
design.create_global_control_gpio("resetn")

# 设置属性
design.set_property("Fled", "OUT_REG", "REG")
design.set_property("Fled", "OUT_CLK_PIN", "Fclk")

# 资源分配
design.assign_pkg_pin("Fled[0]", "J2")
design.assign_pkg_pin("pll_clkin", "C3")
design.assign_pkg_pin("resetn", "F1")

ISF 与统一流程的关系： - ISF 文件在统一编译流程的 PT (Interface Designer) 步骤中执行 - 通过 exec() 逐行执行 Python 代码，design 对象由框架注入 - 详见 Efinity-ISF语法参考.md

9. 设计检查 (Design Check)

Interface Designer 内置设计规则检查，覆盖所有接口块：

检查类别 示例
GPIO 电压冲突、驱动强度
LVDS Bank 兼容性、时钟配置
PLL 频率范围、相位对齐
DDR 时序约束、Bank 分配
MIPI Lane 配置、时序参数
Clock 时钟域、网络驱动规则
Configuration 配置模式兼容性
JTAG 资源冲突

11. 与统一编译流程的关系

在 Efinity 统一编译流程 (efx_run --flow compile) 中：

RTL Design → Interface Designer (PT) → Synthesis → P&R → Bitstream

Interface Designer 阶段： 1. 读取 project XML 中的设备/封装信息 2. 加载 ISF 文件（如果指定） 3. 验证接口配置 4. 生成约束文件（.sdc、.csv、_template.v） 5. 生成 I/O 配置文件
