PLL 与时钟设计

Efinity PLL 与时钟设计

1. PLL 架构概述

Efinity FPGA 的 PLL（Phase-Locked Loop）是基于 VCO（压控振荡器）的模拟硬核模块，通过反馈分频器（Feedback Divider）和输出分频器（Output Divider）从参考时钟生成所需频率。

核心参数关系： - FVCO = FIN × (Feedback Divider) — VCO 频率 - FCLKOUTx = FVCO / CLKOUTx_DIV — 各输出通道频率

PLL 在 Efinity 中通过 Interface Designer（ISF） 配置为硬核，不在 RTL 中直接例化。

来源: ISF 语法参考 §3.1（BLOCK_TYPE 列表），其中 PLL 列为全部器件支持的块类型 [Efinity-ISF语法参考.md §3.1]

2. PLL 配置 via ISF

2.1 create_block 创建 PLL 实例

在 ISF 中通过 design.create_block() 创建 PLL 块：

design.create_block("my_pll", "PLL")

来源: ISF 语法参考 §3（模块创建），C:\Efinity\2026.1\pt\bin\api_service\design.py (DesignAPI.create_block, line 192) [Efinity-ISF语法参考.md §3]

2.2 PLL 属性设置

PLL 属性通过 design.set_property("inst", "PROP_NAME", "value", "PLL") 设置：

属性名 说明 示例值
FIN 输入参考时钟频率（MHz） "50"
CLKOUT0_EN 使能输出通道 0 "TRUE" / "FALSE"
CLKOUT0_DIV 输出通道 0 分频比 "2"（VCO/2）
CLKOUT1_EN ~ CLKOUTx_EN 使能输出通道 1~N "TRUE" / "FALSE"
CLKOUT1_DIV ~ CLKOUTx_DIV 输出通道 1~N 分频比 "4", "8" 等
CLKOUTx_PHASE 输出通道相位偏移（度） "90", "180"
BANDWIDTH PLL 环路带宽 "LOW", "MEDIUM", "HIGH"

来源: ISF 语法参考 §4.2（PLL 属性示例）[Efinity-ISF语法参考.md §4.2]

2.3 绑定 PLL 资源

design.assign_resource("my_pll", "PLL_R0", "PLL")

来源: ISF 语法参考 §5.2（assign_resource），C:\Efinity\2026.1\pt\bin\api_service\design.py (DesignAPI.assign_resource, line 790) [Efinity-ISF语法参考.md §5.2]

2.4 完整 ISF PLL 示例

# === PLL: 50MHz → 100MHz (CLKOUT0) + 200MHz (CLKOUT1) ===
design.create_block("sys_pll", "PLL")
design.set_property("sys_pll", "FIN", "50", "PLL")
design.set_property("sys_pll", "CLKOUT0_EN", "TRUE", "PLL")
design.set_property("sys_pll", "CLKOUT0_DIV", "10", "PLL")     # 1000MHz/10 = 100MHz
design.set_property("sys_pll", "CLKOUT1_EN", "TRUE", "PLL")
design.set_property("sys_pll", "CLKOUT1_DIV", "5", "PLL")      # 1000MHz/5 = 200MHz
design.assign_resource("sys_pll", "PLL_R0", "PLL")

PLL 参考时钟通过 create_pll_input_clock_gpio 创建专用 GPIO 作为 PLL 的时钟源。

来源: ISF 语法参考 §2.1（create_pll_input_clock_gpio）[Efinity-ISF语法参考.md §2.1]

3. PLL 配置 via Interface Designer GUI

在 Efinity GUI 中，可以通过 Interface Designer 图形化配置 PLL：

  1. 打开工程后，进入 Tools → Interface Designer
  2. 在左侧面板中右键 → Create Block → PLL
  3. 在属性面板中设置 FIN、各输出通道的分频比、相位等参数
  4. GUI 实时计算并显示各通道输出频率
  5. 点击 Generate 生成 ISF 和 peri.xml

Interface Designer 生成的配置与手写 ISF 等效。生成的 ISF 文件位于 constraints/ 目录下。

来源: ISF 语法参考 §1（ISF 概述——ISF 位于统一编译流程的 PT 步骤中）[Efinity-ISF语法参考.md §1]

4. PLL 动态重配置（efx_pll_cfg IP）

4.1 功能概述

efx_pll_cfg IP 核允许在 FPGA 运行时动态切换 PLL 配置，无需重新编译比特流。核心特性：

  • 支持最多 85 组 PLL 配置存储和切换
  • 支持恢复到比特流中的原始 PLL 设置（PCR，Peripheral Configuration Register）
  • Single Configuration 和 Multi Configuration 两种模式

来源: C:\Efinity\2026.1\ipm\ip\efx_pll_cfg\ipm\doc\topics\pll-dyn-recfg-core-features.html（Features 页面）

5. PLL Autoreset（efx_pll_autoreset IP）

5.1 功能概述

efx_pll_autoreset 是 Trion PLL Auto-Reset IP 核（Trion 系列专用），用于在 PLL 失锁时自动触发复位脉冲。核心特性：

  • 复位触发后检查 PLL lock 状态
  • 超时后自动发出复位脉冲
  • 支持 1~8 个独立 FSM，每个 FSM 可监控一个或多个 PLL

来源: C:\Efinity\2026.1\ipm\ip\efx_pll_autoreset\ipm\doc\topics\pll-autoreset-core-features.html（Features 页面）

5.2 RTL 参数与端口

参数： | 参数 | 说明 | 范围 | |------|------|------| | N_FSM | FSM 数量 | 1~8，默认 8 |

端口： | 端口 | 方向 | 位宽 | 说明 | |------|------|------|------| | i_pll_rstn | input | N_FSM | 各 PLL 外部复位输入（低有效） | | i_pll_locked | input | N_FSM | 各 PLL 锁定状态输入 | | o_pll_rstn | output | N_FSM | 各 PLL 复位输出（合并外部复位与内部自动复位） | | ro_clk | output | 1 | 内部振荡器时钟输出（用于 FSM 时钟） |

来源: C:\Efinity\2026.1\ipm\ip\efx_pll_autoreset\source\efx_pll_autoreset.v（模块端口与参数声明）

5.3 内部架构

IP 由以下子模块组成： - clk_gen — 内部振荡器时钟生成 - EFX_GBUFCE — 全局时钟缓冲（带时钟使能） - checker — 每个 FSM 的 lock 检查与复位脉冲生成 - 同步器 — lock_filt / lock_sync 两级滤波防止亚稳态

来源: C:\Efinity\2026.1\ipm\ip\efx_pll_autoreset\source\efx_pll_autoreset.v（模块实现）

5.4 参数配置

参数 选项 默认值 说明
FSM Count 1 ~ 8 2 FSM 数量。多个 PLL 可共享一个 FSM（前提是不关心各 PLL 的启停时序）

6. 时钟树规划

6.1 全局时钟 vs 区域时钟

Efinity FPGA 的时钟网络分为：

类型 ISF GPIO 类型 说明
Global Clock (GCLK) create_input_clock_gpio 全局时钟网络，可达全芯片
Regional Clock (RCLK) create_regional_input_clock_gpio 区域时钟，仅 Trion 以上支持
PLL Clock Input create_pll_input_clock_gpio PLL 专用参考时钟输入
Clock Output create_clockout_gpio 时钟输出到引脚

来源: ISF 语法参考 §2.1（GPIO 命令表），C:\Efinity\2026.1\pt\bin\api_service\design.py [Efinity-ISF语法参考.md §2.1]

6.2 时钟 Spine

Efinity 器件的时钟通过 Clock Spine 分布。每个 Clock Spine 可驱动一个区域的逻辑。PLL 的输出通过全局时钟网络或区域时钟网络连接到目标逻辑区域。

6.3 RTL 中的 PLL 连接

在 RTL 中，PLL 输出时钟作为顶层输入端口声明：

// PLL 通过 Interface Designer 配置为硬核，不在 RTL 中例化
// 在 RTL 中只声明 PLL 输出的时钟端口和锁定信号
input  wire pll_clk_out,   // PLL 输出的工作时钟
input  wire pll_locked,    // PLL 锁定指示

来源: Efinity 编码风格指南 §7.3（PLL 配置）[Efinity编码风格.md §7.3]

7. 时钟域策略

7.1 同步时钟域

同一 PLL 的不同输出通道（CLKOUT0, CLKOUT1, ...）之间是同步关系（同源 VCO），不需要 CDC 处理。

7.2 异步时钟域（CDC）

以下情况视为异步时钟域，必须做 CDC 处理：

  • 不同 PLL 实例的输出之间
  • 外部独立晶振时钟与 PLL 输出之间
  • 板上多个独立时钟端口之间

CDC 处理规则见 Efinity 设计规范 §3 [Efinity设计规范.md §3] 和 Efinity 编码风格指南 §6 [Efinity编码风格.md §6]。

7.3 SDC 时钟组声明

# 异步时钟域
set_clock_groups -asynchronous \
    -group [get_clocks clk_50m] \
    -group [get_clocks sys_clk] \
    -group [get_clocks video_clk]

来源: Efinity 编码风格指南 §9.2（时钟分组）[Efinity编码风格.md §9.2]

8. Design Check 时钟规则

Efinity PT（Interface Designer）阶段的 Design Check 包含以下时钟相关规则。违反会导致编译终止。

规则 含义 常见原因与修复
clock_rule_capacity 单个区域连接的时钟超过上限 减少该区域的时钟域数量，或将逻辑分散到更多区域
clock_rule_max_count 核心时钟数量超过最大限制（32） 合并不必要的时钟域，使用时钟使能替代分频时钟
clock_rule_lvds_rx_clock_source PLL 输出时钟驱动不同侧的 LVDS Rx 确保同一侧的 LVDS Rx 使用同一侧 PLL 的输出时钟
clock_rule_pll_ref_clock_lvds_rx PLL 参考时钟与 LVDS Rx 不在同一侧 将 PLL 参考时钟来源调整到 LVDS Rx 同一侧
clock_rule_undefined_name 信号无时钟源定义 在 SDC 中为所有时钟端口声明 create_clock

来源: 任务要求中提供的 Design Check 时钟规则表（clock_rule_*）

9. SSC（Spread-Spectrum Clocking）PLL

扩频 PLL（PLL_SSC）用于降低 EMI（电磁干扰）。在 ISF 中通过 create_block 创建：

design.create_block("ssc_pll", "PLL_SSC")

PLL_SSC 是 BLOCK_TYPE 列表中的独立类型 [Efinity-ISF语法参考.md §3.1]。具体 SSC 参数（调制频率、扩频范围）通过 set_property 设置，以 efinity-python-api.pdf 为准。

来源: ISF 语法参考 §3.1（BLOCK_TYPE 列表含 PLL_SSC），Efinity设计API集成.md §版本兼容（属性以 efinity-python-api.pdf 为准）[Efinity-ISF语法参考.md §3.1]

10. 内部振荡器（OSC）使用

Efinity 器件内置内部振荡器（OSC），可通过 ISF 创建：

design.create_block("my_osc", "OSC")

OSC 在 BLOCK_TYPE 列表中列为所有器件支持的块类型 [Efinity-ISF语法参考.md §3.1]。OSC 通常用于： - 上电初始时钟（PLL 锁定前的过渡时钟） - 低功耗待机时钟 - efx_pll_autoreset 的 FSM 时钟源（见 §5）

来源: ISF 语法参考 §3.1（BLOCK_TYPE 列表含 OSC）[Efinity-ISF语法参考.md §3.1]

11. 时钟不确定性预算

在 SDC 中使用 set_clock_uncertainty 为 STA 预留 jitter / skew 裕量：

# PLL 输出时钟 jitter 预算（通常 0.150~0.300 ns）
set_clock_uncertainty 0.200 [get_clocks sys_clk]

# 外部晶振时钟
set_clock_uncertainty 0.100 [get_clocks clk_50m]

来源: Efinity 设计规范 §4.2（完整约束模板中 set_clock_uncertainty 0.200）[Efinity设计规范.md §4.2]

12. PLL Lock 与系统复位集成

12.1 PLL Lock 合并复位

PLL 锁定信号 pll_locked 必须与外部复位合并：

// PLL 未锁定时保持系统复位
wire async_rst_n = rst_n_i & pll_locked;

来源: Efinity 设计规范 §2.2（与 PLL Lock 合并）[Efinity设计规范.md §2.2]

12.2 异步复位同步释放

合并后的复位信号需要经过同步释放链：

// 3 级同步器：异步断言，同步释放
reg [2:0] rst_sync;
always @(posedge sys_clk or negedge async_rst_n) begin
    if (!async_rst_n)
        rst_sync <= 3'b000;
    else
        rst_sync <= {rst_sync[1:0], 1'b1};
end
wire rst_n = rst_sync[2];

来源: Efinity 设计规范 §2.1（异步复位同步释放）[Efinity设计规范.md §2.1]

13. 时钟命名与编码规范

13.1 时钟命名

信号 命名 示例
输入参考时钟 clk_<freq>m_i clk_50m_i, clk_100m_i
系统工作时钟 sys_clk sys_clk
视频/像素时钟 <domain>_clk video_clk, pixel_clk
PLL 输出 pll_<freq>m pll_200m

来源: Efinity 编码风格指南 §3.2（时钟命名）[Efinity编码风格.md §3.2]

13.2 时钟使能替代分频时钟

禁止使用分频后的时钟驱动逻辑。应使用时钟使能：

// ❌ 禁止
always @(posedge clk_div2) begin
    cnt <= cnt + 1;
end

// ✅ 正确
reg clk_en;
always @(posedge sys_clk) begin
    clk_en <= ~clk_en;  // 2 分频使能
end
always @(posedge sys_clk) begin
    if (clk_en)
        cnt <= cnt + 1;
end

来源: Efinity 编码风格指南 §3.3（时钟使能）[Efinity编码风格.md §3.3]

14. 完整设计示例

14.1 ISF 示例：多时钟域系统

# === 时钟输入 ===
design.create_input_clock_gpio("clk_50m")

# === PLL: 50MHz → 100MHz + 200MHz + 25MHz ===
design.create_block("sys_pll", "PLL")
design.set_property("sys_pll", "FIN", "50", "PLL")
design.set_property("sys_pll", "CLKOUT0_EN", "TRUE", "PLL")
design.set_property("sys_pll", "CLKOUT0_DIV", "10", "PLL")     # 100MHz
design.set_property("sys_pll", "CLKOUT1_EN", "TRUE", "PLL")
design.set_property("sys_pll", "CLKOUT1_DIV", "5", "PLL")      # 200MHz
design.set_property("sys_pll", "CLKOUT2_EN", "TRUE", "PLL")
design.set_property("sys_pll", "CLKOUT2_DIV", "40", "PLL")     # 25MHz
design.assign_resource("sys_pll", "PLL_R0", "PLL")

14.2 SDC 示例：完整时钟约束

# 板上时钟声明
create_clock -name clk_50m  -period 20.000 [get_ports clk_50m]

# PLL 输出时钟（通过 get_pins 引用 PLL 输出引脚）
create_clock -name sys_clk   -period 10.000 [get_pins {sys_pll/CLKOUT0}]
create_clock -name clk_200m  -period  5.000 [get_pins {sys_pll/CLKOUT1}]
create_clock -name clk_25m   -period 40.000 [get_pins {sys_pll/CLKOUT2}]

# 时钟不确定性（jitter 预算）
set_clock_uncertainty 0.200 [get_clocks sys_clk]
set_clock_uncertainty 0.200 [get_clocks clk_200m]

# 异步时钟组（外部晶振 vs PLL 输出）
set_clock_groups -asynchronous \
    -group {clk_50m} \
    -group {sys_clk clk_200m clk_25m}

来源: 综合 ISF 语法参考 [Efinity-ISF语法参考.md]、Efinity 设计规范 §4 [Efinity设计规范.md §4]

14.3 RTL 示例：PLL 与复位集成

module top (
    input  wire clk_50m_i,
    input  wire rst_n_i,
    output wire led_o
);
    // PLL 输出（由 Interface Designer 生成，连接到顶层端口）
    // 实际编译时，Efinity 自动将 PLL 时钟连接到 RTL 中使用的信号

    // ---- PLL Lock 合并复位 ----
    wire async_rst_n = rst_n_i & pll_locked;  // pll_locked 由 PLL 提供

    // ---- 3级同步释放 ----
    reg [2:0] rst_sync;
    always @(posedge sys_clk or negedge async_rst_n) begin
        if (!async_rst_n)
            rst_sync <= 3'b000;
        else
            rst_sync <= {rst_sync[1:0], 1'b1};
    end
    wire rst_n = rst_sync[2];

    // ---- 用户逻辑 ----
    // ...
