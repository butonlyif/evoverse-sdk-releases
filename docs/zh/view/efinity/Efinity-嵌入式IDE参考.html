Efinity 嵌入式 IDE 参考

Efinity 嵌入式软件开发 IDE 参考

版本: v1.0 | 基于 Efinity 2026.1

1. 概述

Efinity 嵌入式软件 IDE（efx_code.bat）是为 Efinix FPGA 中的 RISC-V 处理器（Sapphire SoC / VexRiscv）提供的集成开发环境。它基于 Eclipse CDT + GNU MCU Eclipse 插件 + OpenOCD，支持 standalone (裸机) 和 FreeRTOS 两种软件运行环境。

启动方式：

efx_code.bat [workspace_path]

实际执行：

:: 2026.1.132.1
setlocal
call "%~dp0setup.bat"
"python3.bat" -m els_shell -e %*
endlocal

即通过 els_shell Python 模块启动 Eclipse 嵌入式开发环境。

来源: C:\Efinity\2026.1\bin\efx_code.bat

6. Launch Configuration (启动配置)

Eclipse 风格的 XML launch 配置文件，用于 GDB + OpenOCD 调试会话：

<launchConfiguration type="ilg.gnumcueclipse.debug.gdbjtag.openocd.launchConfigurationType">
    <!-- OpenOCD 设置 -->
    <stringAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerExecutable" value="openocd"/>
    <intAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerGdbPortNumber" value="3333"/>
    <intAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerTelnetPortNumber" value="4444"/>
    <intAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerTclPortNumber" value="6666"/>
    <stringAttribute key="ilg.gnumcueclipse.debug.gdbjtag.openocd.gdbServerOther"
        value="-f ${workspace_loc}\bsp\efinix\EfxSapphireSoc\openocd\ftdi.cfg
               -f ${workspace_loc}\bsp\efinix\EfxSapphireSoc\openocd\debug.cfg"/>

    <!-- GDB 客户端设置 -->
    <stringAttribute key="org.eclipse.cdt.dsf.gdb.DEBUG_NAME" value="riscv-none-embed-gdb"/>
    <stringAttribute key="org.eclipse.cdt.debug.gdbjtag.core.gdbClientOtherCommands"
        value="set mem inaccessible-by-default off
               set arch riscv:rv32
               set remotetimeout 250"/>
    <stringAttribute key="org.eclipse.cdt.debug.gdbjtag.core.stopAt" value="main"/>

    <!-- 连接设置 -->
    <stringAttribute key="org.eclipse.cdt.debug.gdbjtag.core.ipAddress" value="localhost"/>
    <intAttribute key="org.eclipse.cdt.debug.gdbjtag.core.portNumber" value="3333"/>
    <booleanAttribute key="org.eclipse.cdt.debug.gdbjtag.core.useRemoteTarget" value="true"/>
</launchConfiguration>

关键参数： | 参数 | 值 | 说明 | |------|-----|------| | Debugger | riscv-none-embed-gdb | RISC-V GDB 调试器 | | OpenOCD GDB 端口 | 3333 | GDB 连接端口 | | OpenOCD Telnet 端口 | 4444 | Telnet 控制端口 | | OpenOCD Tcl 端口 | 6666 | Tcl 脚本端口 | | 目标地址 | localhost | 本地调试 |

启动配置变体： | 文件 | 用途 | |------|------| | default.launch | 标准 FTDI 调试 | | default_ti.launch | Titanium 设备 | | default_softTap.launch | 软件 TAP 模式 |

7. 编译系统

工具链

  • 编译器: riscv64-unknown-elf-gcc
  • GDB: riscv-none-embed-gdb
  • OpenOCD: 支持 FTDI 接口的 OpenOCD

Makefile 系统

standalone.mk    →  通用 standalone 构建规则
bsp.mk           →  BSP 相关构建规则
riscv64-unknown-elf.mk  →  工具链路径和标志

构建产物

文件 说明

.bin 二进制镜像
.hex Intel HEX 格式

8. Bootloader

10. 中断和异常处理

启动代码（汇编）： | 文件 | 功能 | |------|------| | start.S | 主启动代码（栈设置、BSS 清零、跳转 main）| | start_int.S | 带中断向量表的启动代码 | | smpInit.S | SMP 多核初始化 | | smpFunc.S | SMP 核间通信函数 | | trap.S | 异常/中断处理入口 |

11. Semihosting 支持

通过 semihosting.h 提供 semihosting 功能，允许嵌入式程序通过 JTAG 调试接口与主机通信（如 printf 输出到调试控制台）。
