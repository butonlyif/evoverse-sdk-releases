Efinity 优化策略参考

Efinity 优化策略参考

适用 SDK 版本: v1.0.0

基于 Efinity 2026.1 原生工具参数和官方文档整理。 来源：efx_map --help、efx_pnr --help/--help-verbose、efx_pgm --help、官方 PDF 文档。

1. 综合优化 (efx_map)

1.1 优化模式 (--mode)

模式 描述 适用场景
speed（默认） fMAX 优先 时序紧张的设计
speed2 增强速度模式 比 speed 更激进的速度优化
area 面积优化 资源接近上限的设计
area2 增强面积模式（大型 MUX/选择器树优化） 大型多路选择器密集的设计
cong 缓解拥塞 布线拥塞严重的设计
power 功耗优先 低功耗场景

1.2 重定时 (--retiming)

值 效果
0 禁用
1 启用 — 在组合逻辑前后移动寄存器，均衡路径延迟
2（默认） 高级模式 — 比模式1更激进，对 Titanium 推荐

限制：只能在已有寄存器间重分布，不能创造新寄存器。适用于流水线不够深的组合逻辑路径。

1.3 时序优化 (--seq_opt)

值 效果
0 禁用
1（默认） 启用 — 优化时序逻辑综合结果
--seq-opt-sync-only 仅优化同步 set/reset 逻辑

1.4 DSP 优化

参数 默认值 描述
--dsp-input-regs-packing 1（开） DSP 输入寄存器打包（Titanium）
--dsp-output-regs-packing 1（开） DSP 输出寄存器打包（Titanium）
--dsp-mac-packing 1（开） DSP 乘加（MAC）打包（Titanium）
--mult-decomp-retime 1（开） 宽乘法器分解后重定时
--mult-auto-pipeline 0（关） 宽乘法器自动流水线（设置级数，0-36）
--max_mult -1（无限制） 限制 DSP/Multiplier 数量

1.5 BRAM 优化

参数 默认值 描述
--bram_output_regs_packing 1（开） BRAM 输出寄存器打包
--bram-push-tco-outreg 0（关） BRAM Tco 输出寄存器后推
--max_ram -1（无限制） 限制 BlockRAM 数量
--ram-decomp-mode 0 RAM 分解模式（0=speed, 1=area, 2=power）
--use-logic-for-small-mem 64 小于此 bit 数的存储器用 LE 实现
--use-logic-for-small-rom 64 小于此 bit 数的 ROM 用 LE 实现
--max-bit-blast-mem-size 10240 展开为逻辑的最大存储器 bit 数

1.6 逻辑优化

参数 默认值 描述
--infer-clk-enable 3 时钟使能推断努力级（0=禁用, 1-4 努力递增）
--infer-sync-set-reset 1（开） 推断同步 set/reset 信号到 FF
--fanout-limit 0（无限制） 扇出上限（0=无限制, 1-2000）
--min-ce-fanout 0 FF CE 推断最小扇出
--min-sr-fanout 0 SR 推断最小扇出
--operator-sharing 0（关） 算术运算符和 MUX 资源共享
--optimize-adder-tree 0（关） 优化倾斜加法树
--insert-carry-skip 0（关） 进位跳跃链优化（Titanium）
--blast_const_operand_adders 1（开） 打散常量操作数加法器
--pack-luts-to-comb4 0（关） LUT 打包到 COMB4 原语（Titanium, 0/1/2 努力级）
--create-onehot-fsms 0（关） 创建 one-hot 编码有限状态机

1.7 编译控制

参数 默认值 描述
--hdl-compile-unit 1（单文件） SystemVerilog 编译单元模式（0=多文件, 1=单文件）
--hdl-loop-limit 20000 HDL 循环展开上限
--max_threads -1（自动） 并行线程数

2. P&R 优化 (efx_pnr)

2.1 优化级别 (--optimization_level)

级别 方向 描述
TIMING_1 时序 基本时序优化
TIMING_2 时序 中等时序优化
TIMING_3 时序 激进的时序优化
CONGESTION_1 拥塞 轻度拥塞缓解
CONGESTION_2 拥塞 中度拥塞缓解
CONGESTION_3 拥塞 激进拥塞缓解
POWER_1 功耗 基本功耗优化
POWER_2 功耗 激进功耗优化

提示：空字符串 "" 表示使用工具默认策略。

2.2 布局选项

参数 默认值 描述
--placer_effort_level 2 布局努力级（1=最快, 5=最高质量）
--seed 1 布局随机种子

Placer Effort Level 影响： - 1-2: 快速布局，适合迭代开发 - 3-4: 中等质量，适合时序收敛 - 5: 最高质量，编译时间显著增加（2-3x）

2.3 Seed Sweep

不同 --seed 值产生不同布局结果，对时序有显著影响。

# 自动 Seed Sweep（遍历10个seed）
efx_run_pnr_sweep.bat <prj_xml> sweep_seeds --num_seeds 10

# 遍历优化级别组合
efx_run_pnr_sweep.bat <prj_xml> sweep_opt_levels

2.4 Beneficial Skew (--beneficial_skew)

值 效果
on（默认，Titanium） 利用时钟 skew 改善 setup timing
off 禁用

注意事项： - 可能引入 hold 违例，需额外 hold fixing - 适用于 Titanium 器件族 - 如果遇到 hold 问题，考虑关闭此选项

2.5 打包选项

参数 描述
--packing_level 打包程度：NONE, MINIMAL, BASIC, L1（默认）, L2, L3
--physical_packing DSP 物理打包（基于早期布局结果，on/off）

2.6 布线选项

参数 描述
--max_router_iterations 最大布线迭代次数
--load_route 加载已有布线文件（增量布线）

3. 比特流优化 (efx_pgm)

3.1 配置性能

参数 默认值 描述
--oscillator_clock_divider DIV8 SPI 编程时钟分频（DIV8→DIV4→DIV2→DIV1 加速）
--width 1 配置位宽（x1/x2/x4/x8/x16/x32，更高更快）
--bitstream_compression on 比特流压缩（减小存储，但可能增加配置时间）
--spi_low_power_mode on 编程后 Flash 低功耗

3.2 可靠性

参数 描述
--enable_crc_check 编程时 CRC 校验
--enable_seu_crc_check 用户模式 SEU（单粒子翻转）检测
--seu_mode automatic 或 manual
--seu_enable_correction 使能 SEU 自动修正（需 SEU CRC 先开启）
--seu_correction_mode 修正模式：manual, timer, monitor, autofix
--io_weak_pullup 配置时 IO 弱上拉

4. 时序收敛递进策略

Level 1：零代码改动（工具层面）

  1. 开启 Retiming（--retiming 2，默认已开）
  2. 提高 Placer Effort Level（--placer_effort_level 3-5）
  3. 跑 Seed Sweep（尝试不同随机种子）
  4. 尝试不同 优化级别（--optimization_level TIMING_2/3）
  5. 尝试不同综合模式（--mode speed2）
  6. 用 AOE 自动探索选项组合：
efx_run_aoe.bat run -x <project.xml> -r regular.recipe

Level 2：约束层面（SDC 修改）

  1. 添加 I/O delay 约束（set_input_delay / set_output_delay）
  2. 设置 multicycle path（降低不必要的严格约束）
  3. 设置 clock groups（set_clock_groups -asynchronous）
  4. 设置 false path（异步复位、慢速信号）
  5. 添加 max_delay / min_delay 点对点约束

Level 3：RTL 层面（代码修改）

  1. 在长组合逻辑路径中 插入 Pipeline 寄存器
  2. 优化 CDC（时钟域交叉）结构 — 使用标准同步器
  3. 减少扇出：复制驱动或使用 max_fanout 约束
  4. 优化状态机编码（one-hot vs binary）
  5. 对宽乘法器手动添加流水线
  6. 使用 (* keep *) 或 (* dont_touch *) 保护关键寄存器

5. Titanium 器件优化要点

5.1 架构特征

  • LUT4 基本单元：≥3 级连续 LUT 组合逻辑链容易产生 setup 违例
  • DSP Block：支持 MAC（乘加）打包，输入/输出寄存器打包默认开启
  • 时钟网络：beneficial_skew 默认 on

5.3 时序不收敛时的 Titanium 排查清单

  1. 确认 beneficial_skew 是否引入了 hold 违例（尝试关闭）
  2. 检查是否存在 ≥3 级连续 LUT 组合逻辑路径（插入 Pipeline）
  3. 确认 active_capture_clk_edge 设置为 negedge（Titanium 专用默认值）
  4. 确认 Ti35/Ti60 器件未使用已废弃的 I4/I4L 时序模型
  5. 检查 DSP 打包是否被意外关闭（dsp-*-packing 应为 1）
