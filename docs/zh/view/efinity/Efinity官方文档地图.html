5. EFX_FF 单 SR 引脚证据链专节

结论先行：Efinix 触发器（EFX_FF）只有一个 SR（set/reset）引脚，不存在可分别编码的独立 set 与 reset。这与工作区 RTL 规范"禁止同一寄存器同时编码 set 和 reset"的硬约束互为印证。以下四方证据互相独立、完全一致。

5.1 证据一：maplib 源码（综合后端真身）

证据：C:\Efinity\2026.1\sim_models\maplib\efinix_maplib.v

module EFX_FF(Q, D, CE, CLK, SR);   // 第 21 行：端口表只有一个 SR
行号 内容 含义
16-18 SR_SYNC_PRIORITY 宏默认 1 SR 与 CE 同拍冲突时 SR 优先
21 module EFX_FF(Q, D, CE, CLK, SR); 单一 SR 端口，无独立 SET/RST
27 注释 // 0 CE, 1 SR 优先级仲裁表：CE=0、SR=1

5.2 证据二：官方综合文档端口表

证据：C:\Efinity\2026.1\doc\topics\syn-ff.html（UG-EFN-SOFTWARE-v14.0）

行号 内容
175-181 FF 控制信号列表：时钟使能 CE + 单一 set/reset（SR）
213-215 Table 1 EFX_FF Ports：SR — "Asynchronous/synchronous set/reset"（可配异步或同步，但物理上只有一个）
配图 quan-prim-efx-ff.svg：FF 框图仅一根 SR 引脚

5.3 证据三：行为模型源码

证据：C:\Efinity\2026.1\sim_models\verilog\efx_ff.v

行号 内容
5-9 头注释：D flip-flop with clock enable and single set/reset pin
31 input SR, // asyc/sync set/reset
参数 SR_SYNC（同步/异步选择）、SR_VALUE（置位/复位极性）

5.4 证据四：官方仿真模型表描述

证据：C:\Efinity\2026.1\doc\topics\efn-simulating-models.html Table 1 第 243-249 行

EFX_FF 描述原文："D Flip-flop with Clock Enable and Set/Reset Pin"（单数 Pin）。

5.5 证据链汇总与工程含义

# 证据 层面 关键点
1 efinix_maplib.v 第 21 行 后端 maplib 源码 端口表物理上只有一个 SR
2 syn-ff.html 第 213-215 行 官方综合文档 SR = 异步/同步 set/reset（二选一配置）
3 efx_ff.v 第 31 行 仿真行为模型 行为模型与端口表一致
4 efn-simulating-models.html 第 243-249 行 官方模型总表 描述原文单数 "Set/Reset Pin"

工程含义：

  1. 同时编码 set 与 reset 的 RTL，综合器必须用额外 LUT 模拟第二个控制信号 → 面积膨胀 + 时序恶化（工作区 RTL 规范反例即源于此硬件事实）；
  2. SR 极性/同步性由 ISF/综合属性配置（SR_SYNC、SR_VALUE），不是多一根引脚；
  3. 写 RTL 时每个寄存器只应出现单一复位（或单一置位）路径，见《Efinity设计规范.md》与仓库 RTL 编码规范。
