2.2 时钟定义命令

create_clock

# 官方语法（constraint-create-clock.html L170-172）
create_clock -period <float> [-waveform {ris fall}] [-name <clock name>] [<targets>] [-add]
要点 说明 证据
-name 无 target = 虚拟时钟 只定义名字不挂端口的时钟，工具会打 info 提示；意外虚拟时钟是官方列举的 4 类 SDC 常见错误之一 constraint-create-clock.html L168-206；efn-sdc-mistakes.html L173-216
同一 target 不支持多重时钟赋值 除非加 -add constraint-create-clock.html L168-206
时钟数量影响运行时间 官方 Tip：STA/PNR 运行时间随时钟数增长 constraint-create-clock.html L168-206
最小实例 C:\Efinity\2026.1\examples\helloworld-unified\helloworld.sdc 全文仅 1 行：create_clock -period 10 -name clk [get_ports clk] 该文件 L1

create_generated_clock

# 官方全参数（constraint-create-generated-clock.html L168-172）
create_generated_clock -source <pin/port> (-divide_by <n> | -multiply_by <n>)
    [-duty_cycle <float>] [-invert] [-master_clock <name>] [-phase <deg>]
    [-offset <float>] [-edges <list>] [-edge_shift <list>] [-add] <targets>

要点：必须给 -source；-divide_by / -multiply_by 二选一；-edges / -edge_shift 用于逐边沿描述。证据：constraint-create-generated-clock.html L168-212。仓库硬约束「PLL 必须在 ISF 中创建、RTL 只声明端口」的配套做法是：PLL 输出时钟名出现在 SDC 时须与 ISF 创建的 PLL 输出名精确匹配（工程守则，见 §2.9）。

2.5 IO 约束命令

# 官方要点（constraint-setinput-setoutput-delay.html L168-212）
set_input_delay  [-clock <name>] [-reference_pin <pin>] [-add_delay] <value> <targets>
set_output_delay [-clock <name>] [-reference_pin <pin>] [-add_delay] <value> <targets>
要点 说明 证据
不写 = 完全不分析 不写这两个命令，IO 路径完全不分析（官方原文） constraint-setinput-setoutput-delay.html L179-181
-reference_pin 仅 Titanium/Topaz 支持；Interface Designer 会自动为同步接口信号加上 constraint-setinput-setoutput-delay.html L168-212
-add_delay 不加则后一条命令覆盖前一条 constraint-setinput-setoutput-delay.html L168-212

不要设 0 延迟 工程守则：set_input_delay 0 等于"没有外部时序信息"；慢速信号用 false path 表达（见 §2.9） —

2.7 路径选择：-through 选项与 Object Specifiers

-through 被 set_bus_skew、set_false_path、set_max_delay、set_min_delay、set_multicycle_path 五条命令支持，官方支持的用法（constraint-through-option.html L168-187）：

set_false_path -through [get_pins <pin name1>]
set_false_path -through [get_pins {add*|CI}]
set_false_path -through [get_pins <pin1>] -through [get_pins <pin2>]
set_false_path -through [get_cells {add*}]
set_false_path -through [get_cells <cell1>] -through [get_cells <cell2>]

不支持在一次 -through 里混用多个 get_* 命令（constraint-through-option.html L181-186）：

# ❌ 官方明示不支持
set_false_path -through [[get_pins <pin1>] [get_pins <pin2>]]

2.8 SDC 常见错误（官方 4 类）

出处：C:\Efinity\2026.1\doc\topics\efn-sdc-mistakes.html L173-216。

# 错误类型 官方要点 处置
1 Latch / 组合环 不完整 if/case 产生 latch；Trion/Topaz/Titanium 原生不支持 latch，用 LUT 模拟；时序图不允许环，工具在任意点切环 修 RTL（补 default/else），不靠约束掩盖
2 意外虚拟时钟 -name 带了但没挂 target → 虚拟时钟；工具打 info 虚拟时钟仅用于 set_clock_groups/IO 约束等抽象引用；实体时钟必须挂端口
3 未定义时钟 引用了不存在的时钟名 先 create_clock，名字与 RTL 端口/PLL 输出精确一致
4 约束顺序错误 set_input_delay/set_output_delay 引用时钟之前必须已 create_clock SDC 脚本按时钟定义 → 时钟组 → IO 延迟 → 例外的顺序组织
