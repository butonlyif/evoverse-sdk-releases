Efinity 硬 IP：DDR 参考

Efinity 硬 IP 参考 — DDR

适用版本：Efinity 2026.1（实测安装目录 C:\Efinity\2026.1） 调查日期：2026-09-25 证据来源：本文全部属性名、合法值、依赖关系均逐行实测自 Efinity 2026.1 安装目录内 Python 源码，每条标注 文件:行号。除特别注明外，源码根目录为 C:\Efinity\2026.1\pt\bin\（下文简写为 pt\bin\）。 同系列文档：《Efinity-ISF语法参考.md》《Efinity文件格式-peri.xml.md》《Efinity-DesignAPI方法参考.md》《Efinity硬IP-PLL与OSC参考.md》《Efinity硬IP-接口与JTAG参考.md》

1. 概述与定位

DDR 硬 IP 是 Efinity 器件中的存储控制器硬块（Hard Memory Controller + PHY），通过 Interface Designer（PT）配置，由 unified build 在编译时实例化。2026.1 源码中有两代 Prop 类，build_ddr_prop 按器件自动选择（pt\bin\api_service\property\ddr_prop.py:204-225）：

代 Prop 类 DB block_type ISF 导出器 覆盖存储类型
基础版 DDRProp（ddr_prop.py:56） ddr DDRISFBuilder（pt\bin\api_service\exim\isf_exporter.py:2553） DDR3、LPDDR2、LPDDR3
高级版 DDRAdvProp（ddr_prop.py:1360，继承 DDRProp） adv_ddr DDRAdvISFBuilder（isf_exporter.py:2683） LPDDR4、LPDDR4x 等

选择逻辑（ddr_prop.py:215-225）：器件库支持 ddr → 基础版；支持 adv_ddr → 高级版。

API block_type 字符串："DDR"（pt\bin\api_service\common\object_db.py:51 API_BLOCK_TYPE、:130 otype2str_map）。

本卷是三卷中属性最多的：基础版 88 个 PropId + 高级版 153 个 PropId，其中 AXI 端口属性占大半，§4.5/§7.3 按用户要求逐个列出。

2. 创建三件套

design.create_block("ddr_inst1", "DDR")                          # 1. 创建块
design.set_property("ddr_inst1", "MEMORY_TYPE", "DDR3", "DDR")   # 2. 逐条设属性（第 4 参 "DDR"）
design.assign_resource("ddr_inst1", "<DDR资源名>", "DDR")         # 3. 分配 DDR 硬资源（器件相关）
  • block_type 合法字符串清单：object_db.py:35-59；create_block 对不支持类型抛 PTBlkCreateException（pt\bin\api_service\design.py:229-231）。
  • create_* 是一次性 bootstrap：引导编译后必须注释（AGENTS.md §15；ISF 无 delete 命令）。
  • 官方示例中无 DDR ISF 样本（2026.1 examples 全目录检索无 "DDR" 块实例），本文 §8 示例按属性表构造；构造后务必用 cli/import_gpio.bat --peri <工程>.peri.xml --input <文件>.isf --dry-run 自检（rules-efinity-hard.md §1）。

3. Preset 族专用 API（配置 DDR 的推荐入口）

DDR 是全工具链中唯一带 preset 机制的通用块（get_all_preset_info 仅接受 DDR 与 PMA_DIRECT，design.py:2067）。推荐流程：先 preset 打底，再逐项覆写。

3.1 API 签名（pt\bin\api_service\design.py）

方法 签名/行号 说明
get_all_preset_info design.get_all_preset_info(name: str, block_type: str = "DDR") -> List[Tuple[str, str]]（design.py:2059） 列出器件全部可用 preset（preset 名, 描述）二元组列表；block_type 仅 "DDR"/"PMA_DIRECT" 合法（:2067）
set_preset design.set_preset(...)（design.py:2088） 应用 preset；底层写入 "PRESET" 属性（:2101）
get_preset design.get_preset(...)（design.py:2105） 读取当前 preset 名

3.2 preset 五元组

set_preset 的 preset 数据是五元组，由 DDRPresetService 提供候选（ddr_prop.py:818-831 _set_preset；服务对象初始化 :187）：

元素 属性名 含义
1 MEMORY_TYPE 存储类型（DDR3 / LPDDR2 / LPDDR3 / LPDDR4 / LPDDR4x）
2 DQ_WIDTH 控制器数据位宽（ctrl_width）
3 MEMORY_WIDTH DRAM 器件位宽（dram_width）
4 MEMORY_DENSITY DRAM 容量（dram_density）
5 MEMORY_SPEED 速度档 / 频率（speedbin）

preset 应用后，工具按存储类型把时序参数等批量填成该 preset 的默认值；之后再用 set_property 覆写个别项。

5.2 LPDDR2 / LPDDR3（ddr_api_options.py:38-64 / :66-92）

  • LPDDR2：CL 使用 RL=x/WL=y 联合格式（RL=3/WL=1 … RL=8/WL=4）；FPGA_ITERM 仅 120/OFF；MEM_OTERM 档位 120、34.3、40、48、60、80。
  • LPDDR3：结构与 LPDDR2 同族，具体档位见 ddr_api_options.py:66-92。
  • LPDDR4/LPDDR4x 无静态 map：ddr_api_options.py 在 L92 结束，LPDDR4 合法值由器件库在运行时提供（getattr 动态获取，缺失即空表）。配置 LPDDR4 前先用 get_all_preset_info 确认器件支持，再以 preset 为准。

9. 常见错误与排查

症状 根因 处置
set_property 报属性不存在 基础版/高级版属性混用（如给 LPDDR4 工程设 TRP，或给 DDR3 设 TCCDMW） 先确认器件代（ddr vs adv_ddr），对照 §4/§7 属性表
属性值被拒 未先设 MEMORY_TYPE，合法值 map 未加载（getattr 空 dict） MEMORY_TYPE 必须第一条设置（ISF 导出顺序 memory_type 优先，ddr_prop.py:2360-2374）
LPDDR4 档位查不到 LPDDR4 无静态合法值 map，动态来自器件库 以 get_all_preset_info + GUI 为准；不要硬编码 LPDDR4 档位
时序数值异常 FLOAT 会被格式化为 3 位小数；整数属性（ROW_WIDTH 等）用 INT 校验 时序按 §5 范围给值；DDRPresenter 格式化规则 ddr_prop.py:1082-1094
AXI0_CLK_INOUT_PIN 找不到 2022.1 拼写 bug 的历史名 2026.1 自动纠正为 AXI0_CLK_INPUT_PIN（ddr_prop.py:198-202）；新代码写 INPUT
AXI 引脚设了不生效 TARGET0_EN/TARGET1_EN 未置 1 先使能端口再设引脚（依赖图 :651-760）
RESET/I2C/SEQ 引脚报无关错误 CONTROL_TYPE 模式与引脚组合不匹配 对照 §6：control_type 决定 reset/calib/seq 引脚可见性
二次编译 DDR ... exists 重放 ISF 残留 create_block 注释 create_*（AGENTS.md §15）
preset 应用后个别参数丢失 preset 覆盖了手改值 顺序固定：先 set_preset，后 set_property 覆写
gate delay 改了没效果 GDELAY_OVERRIDE_EN 未开启 先置 1；注意 DB 值是 'Yes'/'No'（:1052-1164）
