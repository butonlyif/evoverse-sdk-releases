Efinity 编程与烧录参考

Efinity 编程与烧录指南

版本: v1.0 | 基于 Efinity 2026.1 (AN033 v1.3 / AN061 / efx_pgm --help)

1. 概述

Efinity 支持多种 FPGA 配置（configuration）模式。本文涵盖配置原理、命令行工具、硬件连接、SEU 防护、FlashShell 脚本 API 以及与 EvoVerse SDK 的集成。

关键术语： - Active 模式：FPGA 作为主设备（master），主动从外部 SPI Flash 读取比特流 - Passive 模式：FPGA 作为从设备（slave），由外部主设备（MCU/CPU/JTAG 调试器）提供比特流 - JTAG：始终可用，不受其他 pin 配置影响

来源：AN033 v1.3 "Titanium Configuration"

专用配置引脚（Titanium）： | 引脚 | 方向 | 说明 | |------|------|------| | CDONE | 输出（开漏，内部上拉） | 配置完成指示 | | CRESET_N | 输入（低有效，内部上拉） | 配置复位 | | TCK, TMS, TDI, TDO | JTAG（内部上拉） | JTAG 接口 | | SSL_N, CDI[0:7], CCK, SSU_N | 多功能（配置后复用为 User IO） | SPI Active/Passive 接口 |

来源：AN033 v1.3 — Dedicated Config Pins

2. 命令行参考

efx_pgm 的所有参数按功能类别组织。

来源：efx_pgm --help 完整输出（Efinity 2026.1）

2.1 基本输入/输出参数

参数 说明
--project-xml arg 工程 XML 文件
--source arg 输入 LBF/HEX 文件
--periph arg 外设配置文件（来自 Interface Designer 的 LPF）
--dest arg 输出 HEX 文件路径
--help 帮助信息
--query_bitstreams 查询设备是否支持比特流（退出码 0=支持）
--query_security_version 查询安全层设备版本号（打印返回值后退出）

来源：efx_pgm --help — Primary Options

2.2 通用配置参数

参数 有效值 说明
--device arg — FPGA 器件型号
--family arg — FPGA 器件族（Trion / Titanium / Topaz）
--displayed_device arg — 写入比特流头部的器件名称
--generate_header arg on / off 是否写入可选头部到比特流
--timestamp arg on / off 是否写入时间戳到比特流头部
--width arg 1,2,4,8,16,32 编程位宽
--settings_file arg — 设置文件路径
--interface_designer_settings arg — Interface Designer 生成的设置文件
--periph_override arg — CSV 文件覆盖 Interface Designer LPF 设置
--mode — FPGA 配置模式

来源：efx_pgm --help — General Options

2.3 HEX 生成选项

参数 有效值 默认值 说明
--oscillator_clock_divider DIV8, DIV4, DIV2, DIV1 DIV8 SPI Active 编程时钟分频
--bitstream_compression on / off on 压缩比特流使能
--optimize_bram_data on / off — 优化 BRAM 帧数据
--spi_low_power_mode on / off on 编程后将 Flash 置于低功耗模式
--io_weak_pullup on / off on 配置期间使能 IO 弱上拉
--jtag_usercode unsigned integer — JTAG USERCODE
--enable_roms on, off, smart smart 使能用户 RAM 中已初始化的存储器
--release_tri_then_reset on / off on 进入用户模式前先释放 IO 三态再复位
--activate_tri_then_reset on / off — 退出用户模式前 IO 三态
--osc_user_enable on / off — 用户模式下启用内部振荡器
--osc_user_div_select DIV8, DIV4, DIV2, DIV1 — 用户模式振荡器分频选择

来源：efx_pgm --help — HEX Generation Options

--flash_addr_2 unsigned integer 多镜像 #2 的 Flash 字节地址

3. 配置模式详解

3.1 模式对比

模式 主/从 接口 典型场景
SPI Active (serial) FPGA 主 SSL_N, CCK, CDI[0], SSU_N 独立上电自启动（最常用）
SPI Active (parallel) FPGA 主 SSL_N, CCK, CDI[0:7], SSU_N 超快速启动
SPI Passive (serial) 外部主 Same as Active but FPGA slave 外部 MCU 提供比特流
SPI Passive (parallel) 外部主 Same as Active parallel 外部高速配置
JTAG 外部调试器 TCK, TMS, TDI, TDO 调试（始终可用）

来源：AN033 v1.3 — Configuration Modes

3.2 SPI Active 指令集

FPGA 在 SPI Active 模式下向 Flash 发送的标准 SPI 读指令：

指令码 模式 说明
0BH x1 Fast Read 单线快速读取
3BH x2 Fast Read 双线快速读取
6BH x4/x8 (双 Flash) 四线/八线快速读取

来源：AN033 v1.3 — SPI Active Instructions

3.3 配置时间估算

配置时间公式（AN061）：

Configuration Time = Bitstream Size ÷ (Config Clock × Data Bus Width)
  • 除数越大，配置越快：降低 --oscillator_clock_divider（DIV8→DIV1）或增加 --width
  • 压缩可减小比特流体积（Titanium 约 50%）

来源：AN061 — Topaz Configuration

4. 器件比特流尺寸

器件族 器件型号 最大比特流大小
Titanium Ti35 / Ti60 13,686,496 bits（~50% 压缩后）
Topaz Tz50 13.7M bits
Topaz Tz75 / Tz100 38.4M bits
Topaz Tz110 / Tz170 50.1M bits
Topaz Tz200 / Tz325 106M bits

来源：AN033 v1.3（Titanium）；AN061（Topaz）

5. 多镜像与远程更新

5.1 多镜像选择（CBSEL）

通过 CBSEL[1:0] 硬件引脚选择从不同的 Flash 地址加载不同的镜像：

  • 需要 --enable_cbsel on
  • 使用 --flash_addr_2、--flash_addr_3、--flash_addr_4 指定各镜像在 Flash 中的起始字节地址
  • 典型用途：Golden Image + Update Image 的双镜像方案

来源：efx_pgm --help；AN033 — Multi-Image

5.2 远程更新（Remote Update）

FPGA 在用户模式下通过内部逻辑触发重新配置：

  • --enable_remote_update on
  • --remote_update_retries N 设置重试次数
  • 通常与 CBSEL 组合使用，实现安全固件更新（更新失败自动回退到 Golden Image）

来源：efx_pgm --help；AN033 — Remote Update

6. SEU 检测与修正

单粒子翻转（SEU）是 SRAM FPGA 在辐射环境中的关键可靠性问题。Efinity 支持两层次的 SEU 防护。

6.1 SEU CRC 检测

参数 有效值 说明
--enable_seu_crc_check on / off 使能用户模式 SEU CRC 检查
--seu_mode automatic / manual 自动扫描（周期触发）或手动触发
--seu_wait_interval unsigned integer 自动模式下两次 CRC 检查的等待间隔

来源：efx_pgm --help；AN061 — SEU

6.2 SEU 修正（Correction）

需先开启 --enable_seu_crc_check。修正模式：

参数 有效值 说明
--seu_enable_correction on / off 使能 SEU 修正
--seu_correction_mode manual, timer, monitor, autofix 修正模式
--seu_correction_timer unsigned integer Timer 模式最大等待时间
--seu_correction_clearable on / off UNFIXABLE 状态可清除
--seu_correction_err_inject on / off 错误注入（调试用）
  • manual：由用户逻辑触发修正
  • timer：定时触发修正
  • monitor：持续监控，检测到错误即修正
  • autofix：自动检测并修正

来源：efx_pgm --help；AN061 — SEU Correction

7. 硬件连接参考

7.1 专用配置引脚

引脚 类型 说明
CDONE 输出，开漏，上拉 配置完成后拉高；可用于复位外部器件或触发下一个动作
CRESET_N 输入，低有效，上拉 拉低可重新触发配置流程
TCK / TMS / TDI / TDO JTAG，上拉 始终可用，与 GPIO 功能无关
SSL_N 多功能 SPI 片选（配置中）；配置后复用为 User IO
CDI[0:7] 多功能 SPI 数据输入（配置中）；配置后复用为 User IO
CCK 多功能 SPI 时钟（配置中）；配置后复用为 User IO
SSU_N 多功能 SPI 从选（配置中）；配置后复用为 User IO

来源：AN033 v1.3 — Dedicated Config Pins

7.2 Topaz 特有

  • JTAG_VCCIO_SEL 引脚用于 BR4 bank 的 JTAG 电压选择
  • 支持 3 字节和 4 字节 SPI Flash 寻址（Titanium Ti35/Ti60 仅 3 字节）

来源：AN061 — Topaz Dedicated Pins；AN033 — Ti35/Ti60 3-byte only

8. FlashShell 脚本 API

Efinity 提供 FlashShell Python API，位于 C:\Efinity\2026.1\pgm\flashshell\，用于脚本化烧录操作：

  • 通过 Python 调用实现自动化烧录流程
  • 可用于产线批量烧录、CI/CD 流水线等场景

来源：C:\Efinity\2026.1\pgm\flashshell\ 目录结构

8.1 编程器目录结构

C:\Efinity\2026.1\pgm\
├── bin/efx_pgm/      — 编程器核心二进制文件
├── bin/flash_db/     — Flash 器件数据库（型号、ID、参数）

9. 与 EvoVerse SDK 集成

9.1 编译流程中的编程步骤

EvoVerse SDK 的编译流程 efx_run --flow compile 已包含pgm步骤：

map → PT(interface) → pnr → pgm

用户无需单独调用 efx_pgm。

来源：EvoVerse SDK buildRunner.ts（toolchain/buildRunner.ts）

9.2 独立编程场景

当需要将已生成的比特流烧录到 FPGA 时，SDK 调用 efx_pgm 并传入工程 XML 和配置模式：

efx_pgm --project-xml <project.xml> --mode active

来源：EvoVerse SDK buildRunner.ts — standalone programming invocation

9.3 编程器 Web UI

SDK 扩展可调用 C:\Efinity\2026.1\pgm\bin\webui\ 中的编程器 Web UI，为用户提供图形化烧录界面。

来源：C:\Efinity\2026.1\pgm\bin\webui\ 目录结构

10. 常见问题排查

问题 可能原因 检查项
烧录失败、Flash 未检测到 Flash 型号不在数据库中 检查 pgm/bin/flash_db/
比特流过大 未启用压缩 确认 --bitstream_compression on（默认开启）
SPI Active 启动失败 时钟分频过高 增大 --oscillator_clock_divider（DIV1→DIV8）
多镜像不工作 CBSEL 引脚未正确配置 确认 --enable_cbsel on 且地址合法
SEU 修正不生效 未开启 CRC 检查 确认 --enable_seu_crc_check on

来源：综合 efx_pgm --help 参数与 AN033/AN061 硬件约束推导的排查指南
