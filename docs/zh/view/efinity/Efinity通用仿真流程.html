Efinity 通用仿真流程

Efinity 通用仿真流程

版本: v1.0 | 基于 Efinity 2026.1 (sim_models / efx_run / efx_map / efx_pnr)

1. 仿真流程全景

Efinity 工具链提供四个层级的仿真流程，从纯 RTL 到最终时序标注的门级网表：

流程 efx_run --flow 仿真层级 时序标注 适用阶段
RTL 仿真 rtlsim 行为级 无 功能验证
综合后仿真 mapsim 门级（综合后） 无 综合正确性验证
P&R 后仿真 pnrsim 门级（布局布线后） SDF 时序验证
PT 级 RTL 仿真 ptsimrtl 行为级（PT 时序） efx_sta 接口时序验证
PT 级全芯片仿真 ptsimfc 全芯片（PT 时序） efx_sta 系统级时序验证

完整编译流程（compile）与仿真的关系：

map → PT(interface) → pnr → pgm
                   ↑ pnrsim 在此之后可用
       ↑ mapsim 在此之后可用
 ↑ rtlsim 无需编译即可运行

来源：efx_run --help — --flow 选项；C:\Efinity\2026.1\scripts\efx_run.py

2. 仿真库

2.1 库文件目录结构

Efinity 仿真模型位于 C:\Efinity\2026.1\sim_models\：

C:\Efinity\2026.1\sim_models\
├── maplib/                              — 综合库（纯 Verilog，通用仿真）
│   ├── efinix_maplib.v                  — 原语映射库
│   ├── efinix_peri_lib.v                — 外设库
│   ├── efxlib_maplib.vdb                — Aldec 编译库
│   └── *.vdb                            — 其他编译 VDB 文件
├── verilog/                             — 门级原语 Verilog 模型
│   ├── efx_add.v, efx_comb4.v           — 算术/组合逻辑原语
│   ├── efx_dpram10.v, efx_dpram_5k.v    — 双端口 Block RAM 原语
│   ├── efx_dsp12.v, efx_dsp24.v, efx_dsp48.v — DSP 原语
│   ├── efx_ff.v, efx_gbufce.v, efx_lut4.v, efx_mult.v
│   ├── efx_ram10.v, efx_ram_10k.v, efx_ram_5k.v, efx_srl8.v
└── vhdl/packages/                       — VHDL 仿真包

来源：C:\Efinity\2026.1\sim_models\ 目录结构

2.2 库初始化（setup_efxlib）

efx_run --flow setup_efxlib 编译 Efinity 仿真库以供第三方仿真器使用：

  • 编译 Verilog 和 VHDL 双语言库
  • 目标仿真器通过 --modelsim（ModelSim/QuestaSim）、--aldec（Active-HDL/Riviera-PRO）、--ncsim（Cadence）选择
# 为 ModelSim 编译库
efx_run.bat --flow setup_efxlib --modelsim

# 为 Aldec 编译库
efx_run.bat --flow setup_efxlib --aldec

来源：efx_run --help — --flow setup_efxlib；efx_run.py 第 178–233 行

2.3 开源仿真器（iverilog）

iverilog 可直接使用 maplib/*.v 文件，无需编译 VDB：

  • 添加 efinix_maplib.v 和 efinix_peri_lib.v 到源文件列表
  • 适用于 RTL 仿真（rtlsim）和基础门级仿真

来源：C:\Efinity\2026.1\sim_models\maplib\ 包含纯 Verilog 库（.v 文件）——可直接被 iverilog 使用

2.4 Aldec 编译库（VDB）

maplib/ 中的 .vdb 文件是预编译的二进制库格式，专用于 Aldec Riviera-PRO / Active-HDL 仿真器：

  • efxlib_maplib.vdb — 主映射库
  • 其他 *.vdb — 辅助库

来源：C:\Efinity\2026.1\sim_models\maplib\ 中包含 .vdb 文件

3. RTL 仿真（rtlsim）

RTL 仿真在行为级验证设计功能，无需综合或布局布线。

# 基本 RTL 仿真
efx_run.bat my_design --flow rtlsim --tb <testbench_top.v> --tb_top <tb_module_name>

# 指定仿真器
efx_run.bat my_design --flow rtlsim --tb tb_top.v --tb_top tb_top --modelsim
efx_run.bat my_design --flow rtlsim --tb tb_top.v --tb_top tb_top --aldec
efx_run.bat my_design --flow rtlsim --tb tb_top.v --tb_top tb_top --ncsim

关键参数：

参数 说明
--tb arg 仿真专用 testbench 文件路径
--tb_top arg 顶层 testbench 模块名称
--modelsim 使用 ModelSim / QuestaSim
--aldec 使用 Aldec Active-HDL / Riviera-PRO
--ncsim 使用 Cadence
--sim_opts arg 直传仿真器的额外选项

来源：efx_run --help — 仿真相关参数

4. 综合后仿真（mapsim）

mapsim 在综合后的门级网表上运行仿真，验证综合工具生成的逻辑是否正确。

4.1 生成综合后网表

efx_map 提供的输出选项：

参数 说明
--write-efx-verilog arg 输出综合后 Verilog 网表（用于 mapsim）
--binary-db arg 输出映射后网表为 Verific 二进制 DB

来源：efx_map --help

4.2 运行 mapsim

# 先综合并输出网表
efx_run.bat my_design --flow map --map_opts write-efx-verilog=post_synth.v

# 然后运行 mapsim
efx_run.bat my_design --flow mapsim --tb tb_top.v --tb_top tb_top

mapsim 使用门级原语模型（sim_models/verilog/ 中的 efx_*.v）作为仿真后端。

来源：efx_run --help — --flow mapsim；efx_map --help — --write-efx-verilog；C:\Efinity\2026.1\sim_models\verilog\

5. P&R 后仿真（pnrsim）

pnrsim 在布局布线后的网表上运行仿真，包含 SDF 时序标注（Standard Delay Format annotation），是最接近实际硬件的仿真层级。

5.1 SDC 约束的作用

efx_pnr 使用的 SDC 约束文件决定时序分析的精度：

参数 说明
--sdc_file SDC 约束文件（pnrsim 中 SDF 标注基于此）
--sdc_filelist 多文件 SDC 列表
--unified_sdc_file Unified 时序分析 SDC
--unified_sdc_filelist Unified SDC 文件列表
--print_critical_path N 打印 N 条关键路径（默认 10）

来源：efx_pnr --help 和 --help-verbose

5.2 运行 pnrsim

# 需先完成 compile 或 pnr
efx_run.bat my_design --flow compile

# 然后运行 pnrsim
efx_run.bat my_design --flow pnrsim --tb tb_top.v --tb_top tb_top
  • pnrsim 使用 P&R 输出的网表 + SDF 延迟文件
  • 仿真模型来自 sim_models/verilog/ 中的门级原语
  • 反映真实的布局布线延迟、时钟偏斜、建立/保持时间

来源：efx_run --help — --flow pnrsim

6. PT 级仿真（ptsimrtl / ptsimfc）

PT 级仿真利用 Interface Designer 的时序模型（efx_sta），在仿真中加入接口级时序标注，适用于验证多模块间接口时序。

6.1 ptsimrtl（PT 级 RTL 仿真）

使用 efx_sta 时序数据 + RTL 行为模型：

efx_run.bat my_design --flow ptsimrtl --tb tb_top.v --tb_top tb_top

6.2 ptsimfc（PT 级全芯片仿真）

全芯片范围的门级仿真 + efx_sta 时序：

efx_run.bat my_design --flow ptsimfc --tb tb_top.v --tb_top tb_top

来源：efx_run --help — --flow ptsimrtl 和 --flow ptsimfc

7. 第三方仿真器集成

仿真器 参数 库格式 特点
ModelSim / QuestaSim --modelsim 编译库（via setup_efxlib） 工业标准，全功能
Aldec Active-HDL / Riviera-PRO --aldec VDB（预编译） efxlib_maplib.vdb 直接可用
Cadence --ncsim 编译库（via setup_efxlib） 企业级仿真
iverilog 手动 maplib/*.v（源文件） 开源，无需编译库

来源：efx_run --help — --modelsim / --aldec / --ncsim；C:\Efinity\2026.1\sim_models\maplib\

7.1 直传仿真器选项

# 向仿真器传递额外选项
efx_run.bat my_design --flow rtlsim --tb tb.v --tb_top tb_top --modelsim --sim_opts "-voptargs=+acc"

来源：efx_run --help — --sim_opts

快速决策表：

需求 推荐流程
快速功能验证 rtlsim
验证综合没有破坏逻辑 mapsim
怀疑时序问题 pnrsim
多模块接口时序验证 ptsimrtl / ptsimfc

9. 与 EvoVerse SDK 集成

9.1 SDK 中的仿真支持

EvoVerse SDK 通过 efx_run 的 --flow 参数选择仿真流程：

# SDK 通过 buildRunner.ts 转发仿真命令
efx_run.bat <project> --flow rtlsim --tb <tb_file> --tb_top <tb_module> --aldec

SDK 本身不实现仿真引擎，而是通过 efx_run 调度第三方仿真器。

来源：EvoVerse SDK buildRunner.ts — efx_run 调用模式

9.2 推荐工作流

  1. 开发阶段：rtlsim 快速迭代功能验证
  2. 综合后：mapsim 验证原语映射正确性
  3. 布局布线后：pnrsim 验证时序收敛
  4. 上板前：确认 pnrsim 通过，再执行 pgm 烧录

来源：基于 Efinity 2026.1 仿真层级定义
