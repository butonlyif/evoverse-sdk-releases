Sapphire SoC 配置

Sapphire SoC 配置指南

版本: v1.0 | 基于 Efinity 2026.1 | 最后更新: 2026-07-30

本文档详细描述 Efinix Sapphire RISC-V SoC 三款 IP 核的配置参数、使用方法、内存映射、BSP 结构和典型应用场景。

1. Sapphire SoC 家族概览

Efinix 提供三款 Sapphire RISC-V SoC IP，覆盖从低成本软核到高性能硬化 SoC 的完整谱系：

特性 efx_soc（Sapphire RV32） efx_soc_rv64（Sapphire RV64） efx_hard_soc（HP SoC）
IP 版本（2026.1） 3.4.0 1.0.0 1.23.0
ISA RV32IMAC RV64IMAC RV64IMAC（硬化）
核心数 1–4 1–4（SMP） 4（硬化）
实现方式 软核（VexRiscv） 软核（VexRiscv） 硬化（ASIC-like）
适用器件族 Trion / Titanium Titanium / Topaz Titanium（Ti375）
L1 Cache 可配置 I$/D$（1–4 way） 可配置 I$/D$（1–4 way） 硬化
L2 Cache 无 可选共享 L2 硬化
FPU 可选（F/D） 可选（F/D） 硬化
MMU 可选 可选（Sv39） 硬化
外部内存 AXI3（可选 DDR3/LPDDR3） AXI4（DDR3/DDR4/LPDDR4） LPDDR4（硬化控制器）
逻辑资源消耗 约 5K–15K LUT 约 15K–30K LUT ~0 LUT（CPU 部分）
典型 fMAX 63–289 MHz 200+ MHz 400+ MHz

来源版本号：C:\Efinity\2026.1\ipm\ip\efx_soc\efx_soc\ipm\ip_component.xml 第 6 行（3.4.0）；efx_soc_rv64\ipm\ip_component.xml 第 6 行（1.0.0）；efx_hard_soc\ipm\component.pickle（1.23.0）。ISA/核心参数：IP 目录 ip_component.xml 端口定义与生成器脚本。

2. SoC 选型指南

应用场景 推荐 SoC 理由
简单 GPIO/外设控制 efx_soc（1 核） 资源开销最小
传感器融合、低速网络 efx_soc（1 核 + DDR3） Trion/Titanium 均可
Linux 系统、高带宽 efx_soc_rv64（1–4 核） RV64 + MMU 必须
高带宽视频处理 efx_soc_rv64 + EVSoC 参考 EVSoC 参考设计
最高性能、最低功耗 efx_hard_soc（仅 Ti375C529） 硬化 CPU 不占 FPGA 资源
入门学习 efx_soc（T8/T20/Xyloni） 最低成本和复杂度

来源：器件适用性来自 IP 目录 fpga 子目录（如 efx_soc_rv64/fpga/fpga_ti180/soc.xml、「Efinity参考设计索引.md」§D–E）。

5. efx_hard_soc（High-Performance SoC）配置详解

5.1 核心特征

efx_hard_soc 是 Ti375 系列专用硬化 4 核 RISC-V SoC，CPU 核心不消耗任何 FPGA 逻辑资源：

  • 模块名：Axi4Peripheral_wrapper
  • 实现方式：ASIC 硬化在 Ti375 硅片上
  • LPDDR4 内存控制器：硬化（内置）
  • AXI4 Slave 接口：供用户逻辑挂接
  • Co-Debug：支持
  • 性能：远高于软核，功耗更低

来源：C:\Efinity\2026.1\ipm\ip\efx_hard_soc\ipm\component.pickle（displayName = "Sapphire High Performance SoC"、isHardIP = 1）。

5.2 关键参数

从 component.pickle 中提取的配置参数（摘要）：

参数 默认值 说明
PLL_SOC_SYS_CLK_REF_FREQ 100 MHz 系统 PLL 参考时钟
PLL_SOC_SYS_CLKOUT1_FREQ 1000 MHz 系统时钟输出
PLL_SOC_MEM_CLKOUT1_FREQ 250 MHz 外设 PLL 输出
PLL_LPDDR4_CLKOUT3_FREQ 533 MHz LPDDR4 时钟
DDR_DATA_WIDTH 32 DDR 数据位宽
DDR_MEMORY_DENSITY 8G 内存密度（2G–16G）
DDR_MEMORY_TYPE LPDDR4x / LPDDR4 内存类型（按器件族）
INTF_UINTR 8 用户中断端口数
CO_DEBUG 0 Co-Debug 开关
INTF_JTAG_TYPE 0（FPGA USER TAP） JTAG 类型
SPI/I2C/GPIO 外设 可选 标准外设（同 RV32/RV64）

来源：C:\Efinity\2026.1\ipm\ip\efx_hard_soc\ipm\component.pickle 中 parameters 段。

5.3 使用限制

  • 仅 Ti375C529 器件支持（参见 EmbeddedSystem-Solution Ti375 分支）
  • 不需要 efx_soc 或 efx_soc_rv64——它是独立 IP
  • BSP 与 efx_hard_soc 的 embedded_sw/ 一起提供

来源：「Efinity参考设计索引.md」§D.1（Ti375C529 使用 efx_hard_soc）。

6. 处理器配置总结

6.1 核心数选择

核心数 适用场景 资源开销
1 GPIO 控制、简单协议桥 最低
2 实时任务 + 后台任务 中等
4 SMP Linux、视频处理 最高

6.2 Cache 配置建议

场景 I$ D$ 理由
裸机小程序 1–4 KB 1–4 KB 片上 RAM 足够
中等应用 4–8 KB 4–8 KB CoreMark/网络协议栈
Linux 16–32 KB 16–32 KB 操作系统所需
AI/推理 8–16 KB 8–16 KB 平衡性能与资源

9. 中断控制器

9.1 CLINT（Core Local Interruptor）

  • 提供软件中断 + 定时器中断
  • 每个核心独立的 mtime / mtimecmp 寄存器
  • 在 v2.0 中替代了旧的 Machine Timer

9.2 PLIC（Platform-Level Interrupt Controller）

  • 管理所有外设中断
  • 支持中断优先级
  • 最多 24 个用户中断源（PLIC ID 可配置）

外设中断 ID 分配：

外设 默认中断 ID
UART0 1
UART1 2
SPI0 4
SPI1 5
I2C0 8
I2C1 9
GPIO0 12, 13
User Interrupt A–H 25–32（可配置）

来源：官方 Sapphire SoC IP Configuration 参数表及 soc.h 中断 ID 定义。

10.1 Bootloader 功能

  • 初始化 DDR 控制器（如有）
  • 从 SPI Flash 加载应用程序到 RAM
  • 跳转到应用程序入口

11.2 Co-Debug 配置

Co-Debug 允许单根 FTDI 线同时调试 RTL 和 RISC-V。在 IP 配置向导中将 CO_DEBUG 设为 ENABLE。

12. SoC + DDR 校准流程

  1. 在 IP 配置向导中启用 DDR
  2. 使用 efx_socddr_calrst IP 处理 DDR 校准和复位序列
  3. 编译 RTL + 生成 .hex
  4. 烧录后，bootloader 执行 DDR 校准
  5. 应用程序从 DDR 运行

来源：官方 AN043（TSE MAC + Sapphire SoC lwIP 示例，DDR 校准流程）。
