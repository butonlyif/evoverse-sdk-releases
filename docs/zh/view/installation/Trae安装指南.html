Trae 安装与首次配置

EvoVerse SDK：Trae 安装指南

适用版本：v1.0.0　更新日期：2026-10-16　推荐宿主：Trae CN / Trae International

上手链路总览

从拿到发布包到开始第一个设计，主线是 6 步：

flowchart LR
    A[获取发布包] --> B[安装 3 个 VSIX]
    B --> C[重启 Trae]
    C --> D[首启引导<br>确认工作区]
    D --> E[Welcome 自动打开]
    E --> F[Sync Catalog]
    F --> G["@evoverse 开工"]

每步的验证方式见对应章节。基础软件（Trae、Python、Git、Efinity、驱动、仿真器）在装 VSIX 之前备齐。

1. 前置条件

项目 要求 说明
操作系统 Windows 10/11 64 位（首选）；macOS 12+；Ubuntu 20.04+ macOS 不能作为完整的 Efinity 编译/烧录工作站
Python 64 位 3.11+ CLI 与 MCP Server 只用标准库，无需 pip 装包
Git 在 PATH 中 EvoVerse: Sync Catalog 拉取板卡目录依赖 Git
Efinity 2026.1+ 真实编译、烧录时需要
仿真器 Icarus Verilog RTL 功能仿真；QuestaSim 也可
硬件 FPGA 核心板 + USB 数据线 清单见 §2

电脑配置建议：8 核 CPU、16 GB 内存（较大工程 32 GB）、30 GB 以上 SSD 可用空间、2 个以上 USB 口。

2. 硬件准备

  1. EvoVerse/Efinix FPGA 核心板（例如 Catalog 中的 ws-e1）；
  2. 匹配的底板 / Carrier / 客户自研板；
  3. 符合板卡规格的电源——不要凭接口外形猜测电压和极性；
  4. 可传输数据的 USB 线——只充电线不能用于 JTAG/串口；
  5. 板载 FTDI 调试接口，或 FT2232H/FT4232H JTAG 模块；
  6. 需要串口日志时，备板载 USB-UART 或独立 3.3 V USB-UART；
  7. 传感器 / MIPI / 显示 / 网络外设按需。

连接前阅读 Catalog 中的板卡规格（装好并同步 Catalog 后可用）：

~/evoverse-sdk/catalog/boards/<board-id>/<board-id>.md
~/evoverse-sdk/catalog/boards/<board-id>/docs/

3. 安装基础软件

3.1 安装 Trae

  1. 从 Trae 官方下载页安装 Trae CN 或 Trae International；
  2. 启动并完成账号登录。

验证：命令面板执行 Trae: Show Version 能返回版本号。

3.2 安装 Python 3.11+

  1. 从 Python 官网安装 64 位 Python 3.11 或更新版本；
  2. 勾选 Add Python to PATH。

验证：

py -3 --version     # Windows
python3 --version   # macOS / Linux

输出必须是 3.11 或更高。版本不足时首启引导会报 SYSTEM_PYTHON_MISSING，Python 相关能力被禁用。客户 VSIX 不需要 Node.js / npm。

3.3 安装 Git

  1. 从 Git 官网安装，Windows 安装时选默认选项（含 Git Credential Manager）；
  2. 已装 GitHub CLI 的也可用其认证。

验证：

git --version

3.4 安装 Efinity 2026.1+

  1. 从 Efinix Support Center 获取安装包，按该版本官方指南完成安装与许可证配置；
  2. 记录 Efinity 根目录（例如 C:\Efinity\2026.1）。

验证：根目录下存在 bin/setup.bat（Windows）或 bin/setup.sh，以及 bin/efx_run.bat。EvoVerse 每次运行工具时会调用 Efinity 的 setup 脚本建立子进程环境，无需永久修改 PATH。

3.5 安装 FPGA USB/JTAG 驱动

  • Windows：按板卡用户手册与 Efinity 安装指南使用 Zadig/指定驱动；不要盲目替换复合 FTDI 设备的所有接口，先确认板卡文档要求的 interface；
  • macOS：Efinity 安装包自带驱动；
  • Linux：断开板卡后执行 sudo <EFINITY_HOME>/bin/install_usb_driver.sh，重载 udev 规则后重新连接板卡。

3.6 安装 Icarus Verilog

  • macOS：brew install icarus-verilog；
  • Linux：sudo apt install iverilog；
  • Windows：安装预编译版本并加入 PATH。

验证：iverilog -V 与 vvp -V 均能输出版本号。

3.7 可选：RISC-V 软件工具链

仅使用 Sapphire/RISC-V SoC 时需要。装好后可在 Trae 中执行 EvoVerse: Download & Install RISC-V Toolchain 自动安装，或手动安装后设置 evoverse.riscvToolchainPath。

4. 获取发布包

  1. 拿到客户交付包 EvoVerse-SDK-v1.0.0.tar.gz；
  2. 在包所在目录完整解压（Windows 10 1803+ 自带 tar，不会出现 zip 解压的路径过长报错）：
tar -xzf EvoVerse-SDK-v*.tar.gz

验证：解压目录下能看到 deploy.ps1 / deploy.sh 与 3 个 .vsix。START-HERE.md 和 docs/site/customer-portal.html 是入口文档。

5. 安装 3 个 VSIX

v1.0.0 交付 3 个同版本扩展：

VSIX 作用 是否必装
evoverse-sdk-1.0.0.vsix SDK 核心：Welcome、Catalog、Workbench 外壳、CLI / MCP 必装
evoverse-efinity-adapter-1.0.0.vsix Efinity 编译 / 时序 / 调试 / 烧录 / IP FPGA 开发必装
evoverse-rk3588-adapter-1.0.0.vsix RK3588 软件验证闭环 做 RISC-V 软件时安装

三个 VSIX 版本必须一致；混用不同版本不受支持。

5.1 方式 A：一键部署（推荐）

在解压后的包目录打开 PowerShell：

.\deploy.ps1 -Target trae

macOS / Linux：

./deploy.sh --target trae

脚本按依赖顺序安装 Core、两个 Adapter 与 Skills；可选 Adapter 在包内缺失时跳过并提示。Video Sim 已内嵌于 Core VSIX，无需单独安装。

验证：扩展面板中已安装的 EvoVerse 扩展均为 Enabled 状态。

5.2 方式 B：扩展面板手动安装

  1. 按 Ctrl+Shift+X（macOS：Cmd+Shift+X）打开扩展面板；
  2. 点右上角 ... → Install from VSIX...；
  3. 按上表顺序逐个选择 VSIX。

或用命令行：

trae --install-extension D:\packages\evoverse-sdk-1.0.0.vsix
trae --install-extension D:\packages\evoverse-efinity-adapter-1.0.0.vsix
trae --install-extension D:\packages\evoverse-rk3588-adapter-1.0.0.vsix

6. 重启 Trae 并完成首次引导

  1. 完全退出并重启 Trae，让扩展激活；
  2. 首次激活时弹窗 "Set up EvoVerse SDK?"，选择 Yes, set up。引导会在默认工作区 ~/evoverse-sdk 建立 Catalog、工程与运行时目录（可用 evoverse.home 修改路径），不修改系统文件；
  3. 观察 Output → EvoVerse SDK，引导逐项输出，全部为 ✓ 后出现 === EvoVerse SDK ready ===：
  4. EVOVERSE_HOME ready at …——工作区就绪；
  5. Deployed Efinity knowledge base——知识库部署；
  6. MCP integration: …——写入 ~/.trae/mcp.json 的 mcpServers.evoverse（仅合并，不覆盖其它条目；覆盖前备份为 *.evoverse.bak）；
  7. Agent rule: …——写入 ~/.trae/user_rules/ 下的 evoverse.md 与 evoverse-rtl-style.md；
  8. CLI works: …——CLI 冒烟测试；
  9. Git 不在 PATH 时会有 ! git not found 警告，装好 Git 后 Sync Catalog 才可用；
  10. Python 缺失或版本不足时报 SYSTEM_PYTHON_MISSING，装好 Python 3.11+ 后重跑引导；
  11. 完成后出现提示 "Restart the host to load the MCP server."，选 Restart now 再次重启。

验证：重启后 Welcome 页自动打开。没有自动打开时，命令面板执行 EvoVerse: Show Welcome（evoverse.welcome）。

弹窗当时选了 Later、或需要重跑引导时，执行 EvoVerse: Set Up (re-run bootstrap)（evoverse.setup）。标准 VS Code 不会写入 ~/.trae，宿主差异见 HOST-DIFFERENCES.md。

7. 同步 Catalog

首次安装时 Catalog 为空，界面与 MCP 报 CATALOG_NOT_INSTALLED，这是预期状态，不是故障。

  1. 运行 EvoVerse: Sync Catalog（evoverse.syncCatalog）。同步默认拉取官方公开发布仓库（evoverse-catalog-release），无需 GitHub 账号；GitHub 不可达（网络错误）时自动改从 Gitee 国内镜像抓取同一发布，回执记录实际使用的仓库；完成后写入回执 catalog-sync-receipt.json；
  2. 运行 EvoVerse: Catalog Status（evoverse.catalogStatus），或终端执行 evoverse catalog status --json，记录 state、location 与回执里的 catalog_version、commit。

如需改用自建镜像或私有仓库，可用 evoverse sync --repository <URL> 或环境变量 EVOVERSE_CATALOG_REPOSITORY 覆盖仓库地址。

验证：Welcome 页 Board Catalog 面板能列出板卡（如 ws-e1）。同步失败不影响已有本地内容，修复网络后重新同步即可。

8. 验证安装

  1. 左侧活动栏能打开 EvoVerse；
  2. Workbench 能显示已安装的 Adapter（装了 Efinity Adapter 就应有对应条目）；
  3. 运行 EvoVerse: Health Check（evoverse.sdkHealthCheck），确认 Python / Efinity / MCP / 仿真器 / CLI / Adapter 各项通过（Welcome 页也有 SDK 体检面板）；
  4. 设置中确认 evoverse.efinityPath 指向实际 Efinity 安装目录。

9. 开始使用

  1. 自然语言开工：在 Chat 面板输入 @evoverse 描述需求：

text @evoverse 我要在 ws-e1 上实现 MIPI 到 USB，中间用 DDR 缓冲

SDK 会先确认工作方式：可靠设计流程或自由开发。不带 @evoverse 的普通对话保持自由开发，不自动启用可靠流程，也不向客户工程生成专用规则文件。

  1. Workbench 选流程：也可以在 Workbench 的 Project Control 下拉中选择设计流程，对应命令 EvoVerse: Select Design Flow（evoverse.selectDesignFlow）；
  2. Workbench 六个 Tab：Home / Build / Timing / Debug / SW / IP；
  3. 编译：Build Tab 或命令面板 Toolchain: Build（evoverse.build）。Build 由 Efinity Adapter 执行 efx_run --flow compile，状态栏显示 Build: Ready / Running / Failed；
  4. 时序诊断：Toolchain: Diagnose Timing Violations（evoverse.diagnoseTiming）；
  5. 烧板：Toolchain: Program FPGA（evoverse.program）。

日常开发全流程见用户使用手册。

10. 故障排查

10.1 Chat 面板找不到 @evoverse

  1. 确认 ~/.trae/mcp.json 中存在 mcpServers.evoverse；
  2. 确认完成过 "Restart the host to load the MCP server." 提示后的重启；
  3. Trae → Settings → MCP，确认 evoverse Server 状态为 running；
  4. Chat 面板输入 @，下拉列表应出现 evoverse。

10.2 ~/.trae/mcp.json 被破坏

SDK 写入前会备份为 ~/.trae/mcp.json.evoverse.bak。从备份恢复后重跑 EvoVerse: Set Up (re-run bootstrap)：

cp ~/.trae/mcp.json.evoverse.bak ~/.trae/mcp.json

10.3 Agent 规则与团队规则冲突

  • 规则源在 ~/evoverse-sdk/agent-rules/，不要直接改 ~/.trae/user_rules/*.md；
  • 项目级规则写到 .github/copilot-instructions.md；
  • 确需改用户规则时先备份，并在 SDK 升级后人工合并。

10.4 引导报 SYSTEM_PYTHON_MISSING

安装或修正 Python 3.11+（见 §3.2），或把 evoverse.pythonPath 指向真实解释器后重跑 EvoVerse: Set Up (re-run bootstrap)。

10.5 其他

安装类问题（Sync Catalog 失败、Health Check 不通过、找不到 Efinity）对照部署指南的「遇到问题」表处理。
