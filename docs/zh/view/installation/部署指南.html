客户安装与部署

EvoVerse SDK 客户安装与部署

适用版本：v1.0.0　发布基线：2026-09-30　推荐宿主：Trae

适用对象

拿到客户交付 tar.gz 包，需要安装 EvoVerse SDK、Workbench Adapter 和可选 Video Sim 的最终用户。

你将完成什么

安装交付包中的扩展，运行首次设置，确认 Catalog、工具链和角色文档入口可用。

前置条件

  • Trae；标准 VS Code 也支持，但首次使用优先按 Trae 路线操作。
  • 64 位 Python 3.11+。
  • Git 在 PATH 中（EvoVerse: Sync Catalog 依赖普通 Git 同步）。
  • 需要真实 FPGA 编译、烧录时安装 Efinity 2026.1+。
  • 普通 RTL 仿真需要 Icarus Verilog 或 QuestaSim。

步骤

1. 解压并阅读入口

完整解压客户包后再运行脚本。在客户包所在目录执行：

tar -xzf EvoVerse-SDK-v*.tar.gz

Windows 10 1803+ 自带 tar，走长路径，不会出现 zip 解压的「路径太长」报错（也可用 7-Zip）。解压后打开 START-HERE.md 或 docs/site/customer-portal.html，确认可以看到三条角色路线。

2. 一键部署

在客户包目录打开 PowerShell：

.\deploy.ps1 -Target trae

脚本按依赖顺序安装 3 个 VSIX（Core、Efinity Adapter、RK3588 Adapter）和 Skills（两个 Adapter 为可选组件，包内缺失时跳过并提示）。Video Sim 已内嵌于 Core VSIX，无需单独安装。若客户策略禁止脚本安装，可在 Trae 的扩展面板按相同顺序选择 Install from VSIX…。

3. 首次设置

  1. 在命令面板运行 EvoVerse: Set Up (re-run bootstrap)。
  2. 等待 runtime 和宿主集成完成。首次安装时 Catalog 为空是预期状态，界面与 MCP 会报告 CATALOG_NOT_INSTALLED。
  3. Trae 提示重启时完全重启宿主，使 MCP 配置生效。
  4. 在设置中确认 evoverse.efinityPath 指向实际 Efinity 安装目录。

3.1 同步 Catalog

  1. 运行 EvoVerse: Sync Catalog。同步默认拉取官方公开发布仓库（evoverse-catalog-release），无需 GitHub 账号；完成后写入回执 catalog-sync-receipt.json，记录 catalog_version 与 commit。
  2. 运行 evoverse catalog status --json，记录 state、location 与回执里的 catalog_version、commit。
  3. 网络失败时修复后重试；同步失败不影响本地现有 Catalog（官方条目才被覆盖，本地内容不动）。本地 catalog 目录损坏时，重新运行 EvoVerse: Sync Catalog 重建即可；工作区 .evoverse/catalog.json 指针文件记录受信物料根目录（catalogRoot）。
  4. 如需改用自建镜像或私有仓库，可通过命令 evoverse sync --repository <URL> 或环境变量 EVOVERSE_CATALOG_REPOSITORY 覆盖仓库地址。

4. 验证安装

  1. 左侧活动栏能打开 EvoVerse。
  2. Workbench 能显示已安装的 Adapter。
  3. Board Catalog 能列出当前 catalog 板卡。
  4. 命令面板能找到 EvoVerse: 和 Toolchain: 命令。
  5. 运行 EvoVerse: Health Check，确认 Python / Efinity / MCP / 仿真器 / CLI / Adapter 各项体检通过（Welcome 页也有 SDK 体检面板）。
  6. 打开客户门户，按所选角色进入第一个任务。

标准 VS Code 差异

  • 安装同一组 VSIX，不需要专用安装包。
  • 扩展不会写入 Trae 私有的 .trae 配置。
  • MCP 和模型能力按 VS Code 当前公开接口及客户环境配置；确定性仿真、编译和规则诊断不依赖 AI。
  • 详细步骤见 VS Code 安装指南。

成功标志

  • Core 与所需 Adapter 均处于 Enabled 状态。
  • Set Up 有明确完成结果，Output 中没有未处理错误。
  • 能打开客户文档门户、Catalog 和 Workbench。
  • 若尚未连接真实板卡，只能确认安装与入口可用，不能宣称烧录或硬件验证通过。

遇到问题

症状 处理
找不到 Python 安装 Python 3.11+，或设置 evoverse.pythonPath 为真实可执行文件
没有 EvoVerse 图标 在 Extensions 确认 Core 已启用，再查看 EvoVerse Output
Catalog 为空 / CATALOG_NOT_INSTALLED 运行 EvoVerse: Sync Catalog（默认走公开发布仓库，无需 GitHub 账号）
Trae Agent 看不到 MCP 完全退出 Trae 进程后重新打开
Build 找不到 Efinity 检查 evoverse.efinityPath，再运行工具链检测
Efinity 返回编译错误 按错误文本查询 常见编译错误排查

卸载

在 Extensions 中卸载所装 VSIX。卸载扩展不会自动删除客户工程和 evoverse.home 下的数据；确认不再需要后再手工处理用户数据。
