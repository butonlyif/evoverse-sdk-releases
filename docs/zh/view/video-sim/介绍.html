Video Sim 平台介绍

Video Sim 平台介绍

EvoVerse SDK v1.0.0 · Video Sim v1.0.1 · 2026-09-30

定位

Video Sim（又称 VIP 仿真验证平台）是 EvoVerse 的视频 IP 子产品： 给一张图进去，经过你的 RTL 模块，拿到一张图出来，最后告诉你处理得好不好。 它跑在 PC 仿真（iverilog）上，不烧板、不综合，负责算法与图像级验证；板级验证交给 EvoVerse SDK。

视频 IP 开发有四个反复出现的痛点，各有对应解法：

痛点 解法
把真实图像塞进 RTL 仿真要写一堆 hex 转换脚本 图像/视频 → 仿真激励自动完成，输出 $readmemh 可读 hex
仿真跑完只能看波形，无法直观判断画质 结果还原：hex 自动转回 PNG/MP4，直接看效果
RTL 实现对不对，没有客观判定 金标准比对：Python 参考模型按位复现 RTL 定点运算，自动 PASS / FAIL
调一个参数不知道影响多大 多维度质量分析：锐度、白平衡、PSNR、直方图、Gamma 曲线，弹出独立面板

适合谁：

  • FPGA 验证工程师 — 视频 IP 的图像级 PASS/FAIL 判定
  • 课题学生 — 学习视频处理算法并验证 RTL 实现
  • IP 开发者 — 把算法 → RTL → 仿真 → 金标准 → 回归测试完整串起来

平台组成

组成 说明
仿真模板 示例 IP（passthrough）、AXI-Stream BFM + Testbench、Python 工具链（scripts/sim.py 编排）
IDE 扩展 Trae / VS Code 图形控制台：新建项目、运行仿真、查看分析面板，无需命令行
金标准与分析 Python 参考模型按位比对 + 6 项质量分析（PSNR · 锐度 · 白平衡 · 直方图 · 差异热力图 · Gamma 曲线）

完整工作流：

┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 真实图像  │ → │ 仿真激励  │ → │ 你的 RTL │ → │ 仿真输出  │
│ / 视频   │   │ (hex)    │   │ IP 模块   │   │ (hex)    │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
                                                 ↓
              ┌──────────┐   ┌──────────┐   ┌──────────┐
              │ PASS /   │ ← │ 金标准比对│ ← │ 结果还原  │
              │ FAIL     │   │  + 6 项   │   │ (PNG/MP4) │
              └──────────┘   │ 质量分析  │   └──────────┘
                             └──────────┘

核心能力：

  • 图像/视频 → 仿真激励 — 自动转换为 Verilog $readmemh hex
  • 一键仿真 — iverilog 编译 + 运行 + 结果采集全自动
  • 结果还原 — 仿真输出 hex 自动还原为 PNG/MP4
  • 金标准比对 — Python 参考模型按位复现，自动判定 PASS / FAIL
  • 9 种图卡 — 渐变 / 色块 / 棋盘格 / 噪声 / 坏点等，用于系统化验证
  • DDR 帧缓冲 — AXI4 DDR 模型 + ping-pong 双槽（VIP08）
  • Vibe Coding — 自然语言描述 → 自动生成 RTL + golden + TB + regdef（VIP09）
  • 回归测试 — make regression 一键跑全部 snapshot（VIP10）

工具链：iverilog + Python 3.11+ + Pillow / NumPy / OpenCV。 跨平台一致，Windows 上不需要 GNU Make：

平台 安装仿真器 构建方式
macOS brew install icarus-verilog make 或 python scripts/sim.py
Linux sudo apt install iverilog make 或 python scripts/sim.py
Windows scoop install icarus-verilog python scripts/sim.py（无需 make）

可选装 GTKWave（brew install gtkwave / scoop install gtkwave / sudo apt install gtkwave）或 VS Code 扩展 VaporView（扩展市场搜 lramseyer.vaporview）看波形。Python 图像依赖（opencv/numpy/pillow）无需手动安装，新建项目时自动创建 .venv 并装好。

入口

从 离线客户文档门户 的 Video Sim 任务进入。 历史 VIP01-VIP10 教程树已退出当前工作目录，不再作为入口。

上手步骤（细节见用户使用说明书）：

  1. 安装 evoverse-sdk VSIX。Video Sim 内嵌其中，无需单独安装：

bash code --install-extension evoverse-sdk-<版本>.vsix

也可在 IDE 内安装：扩展面板 → ··· → Install from VSIX → 选择客户交付包根目录中的 evoverse-sdk-<版本>.vsix。 装完重新加载窗口：Ctrl+Shift+P (Windows) / Cmd+Shift+P (Mac) → Developer: Reload Window。

  1. 控制台点击「新建仿真项目」，扩展自动复制工具包并创建 Python 虚拟环境。

  2. 开发 IP 并运行仿真：

```bash # 方式一：Spec 驱动（推荐，RTL + 金标准同时生成） python scripts/gen_ip_spec.py --spec specs/my_filter.yaml

# 方式二：AI 生成（Vibe Coding） # 在 Trae 中描述需求，按 .trae/rules/project_rules.md 自动生成

# 命令行跑仿真；或在控制台点击「运行仿真」 python scripts/sim.py all IP=passthrough WIDTH=64 HEIGHT=48 ```

使用边界

场景 用什么
FPGA 板级验证（烧录、时序、调试） EvoVerse SDK（即 evoverse-sdk VSIX）
算法 / 图像级验证（不烧板、不综合） Video Sim（内嵌于 evoverse-sdk VSIX）

Video Sim 只覆盖 PC 仿真，不含板级烧录、时序分析和硬件调试。 当前版本 v1.0.1，变更清单见发布说明。
